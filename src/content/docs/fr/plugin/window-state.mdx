## Utilisation

Après l'ajout du plugin window-state, toutes les fenêtres mémoriseront leur état lorsque l'application sera fermée et retrouveront leur état précédent au prochain lancement.

Vous pouvez également accéder au plugin window-state en JavaScript et en Rust.

:::tip
La restauration de l'état se produit après la création de la fenêtre.
Pour éviter que la fenêtre ne clignote, vous pouvez définir `visible` sur `false` lors de sa création ;
le plugin affichera la fenêtre lorsqu'il restaurera l'état.
:::

### JavaScript

Vous pouvez utiliser `saveWindowState` pour enregistrer manuellement l'état de la fenêtre :

```javascript
import { saveWindowState, StateFlags } from '@tauri-apps/plugin-window-state';
// when using `"withGlobalTauri": true`, you may use
// const { saveWindowState, StateFlags } = window.__TAURI__.windowState;

saveWindowState(StateFlags.ALL);
```

De la même façon, vous pouvez restaurer manuellement l'état d'une fenêtre depuis le disque :

```javascript
import {
  restoreStateCurrent,
  StateFlags,
} from '@tauri-apps/plugin-window-state';
// when using `"withGlobalTauri": true`, you may use
// const { restoreStateCurrent, StateFlags } = window.__TAURI__.windowState;

restoreStateCurrent(StateFlags.ALL);
```

### Rust

Vous pouvez utiliser la méthode `save_window_state()` exposée par le trait `AppHandleExt` :

```rust
use tauri_plugin_window_state::{AppHandleExt, StateFlags};

// `tauri::AppHandle` now has the following additional method
app.save_window_state(StateFlags::all()); // will save the state of all open windows to disk
```

De la même façon, vous pouvez restaurer manuellement l'état d'une fenêtre depuis le disque avec la méthode `restore_state()` exposée par le trait `WindowExt` :

```rust
use tauri_plugin_window_state::{WindowExt, StateFlags};

// all `Window` types now have the following additional method
window.restore_state(StateFlags::all()); // will restore the window's state from disk
```

## Permissions

Par défaut, toutes les commandes et portées potentiellement dangereuses du plugin sont bloquées et ne sont pas accessibles. Vous devez modifier les permissions dans votre configuration `capabilities` pour les activer.

Consultez la [vue d'ensemble des capabilities](/fr/security/capabilities/) pour plus d'informations et le [guide pas à pas](/fr/learn/security/using-plugin-permissions/) pour utiliser les permissions des plugins.

```json title="src-tauri/capabilities/default.json" ins={4}
{
  "permissions": [
    ...,
    "window-state:default",
  ]
}
```
