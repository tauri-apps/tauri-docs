### Envoyer une notification

Suivez ces étapes pour envoyer une notification :

<Steps>
1. Vérifier si la permission est accordée

2. Demander la permission si elle n'est pas accordée

3. Envoyer la notification

</Steps>

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```javascript
import {
  isPermissionGranted,
  requestPermission,
  sendNotification,
} from '@tauri-apps/plugin-notification';
// avec `"withGlobalTauri": true`, vous pouvez utiliser
// const { isPermissionGranted, requestPermission, sendNotification, } = window.__TAURI__.notification;

// Avez-vous l'autorisation d'envoyer une notification ?
let permissionGranted = await isPermissionGranted();

// Sinon, nous devons la demander
if (!permissionGranted) {
  const permission = await requestPermission();
  permissionGranted = permission === 'granted';
}

// Une fois l'autorisation accordée, nous pouvons envoyer la notification
if (permissionGranted) {
  sendNotification({ title: 'Tauri', body: 'Tauri is awesome!' });
}
```

</TabItem>
<TabItem label="Rust">

```rust
tauri::Builder::default()
    .plugin(tauri_plugin_notification::init())
    .setup(|app| {
        use tauri_plugin_notification::NotificationExt;
        app.notification()
            .builder()
            .title("Tauri")
            .body("Tauri is awesome")
            .show()
            .unwrap();

        Ok(())
    })
    .run(tauri::generate_context!())
    .expect("error while running tauri application");
```

</TabItem>

### Actions

:::caution[Mobile uniquement]
L'API Actions est disponible uniquement sur les plateformes mobiles.
:::

Les actions ajoutent des boutons et des champs interactifs aux notifications. Utilisez-les pour créer une expérience réactive pour vos utilisateurs.

#### Enregistrer des types d'actions

Enregistrez des types d'actions pour définir des éléments interactifs :

```javascript
import { registerActionTypes } from '@tauri-apps/plugin-notification';

await registerActionTypes([
  {
    id: 'messages',
    actions: [
      {
        id: 'reply',
        title: 'Reply',
        input: true,
        inputButtonTitle: 'Send',
        inputPlaceholder: 'Type your reply...',
      },
      {
        id: 'mark-read',
        title: 'Mark as Read',
        foreground: false,
      },
    ],
  },
]);
```

#### Propriétés des actions

| Propriété                | Description                                         |
| ------------------------ | --------------------------------------------------- |
| `id`                     | Identifiant unique de l'action                      |
| `title`                  | Texte affiché pour le bouton de l'action            |
| `requiresAuthentication` | Nécessite l'authentification de l'appareil          |
| `foreground`             | Place l'app au premier plan lorsque l'action arrive |
| `destructive`            | Affiche l'action en rouge sur iOS                   |
| `input`                  | Active la saisie de texte                           |
| `inputButtonTitle`       | Texte du bouton d'envoi du champ                    |
| `inputPlaceholder`       | Texte d'espace réservé du champ de saisie           |

#### Écouter les actions

Écoutez les interactions utilisateur avec les actions de notification :

```javascript
import { onAction } from '@tauri-apps/plugin-notification';

await onAction((notification) => {
  console.log('Action performed:', notification);
});
```

### Pièces jointes

Les pièces jointes ajoutent du contenu multimédia aux notifications. La prise en charge varie selon la plateforme.

```javascript
import { sendNotification } from '@tauri-apps/plugin-notification';

sendNotification({
  title: 'New Image',
  body: 'Check out this picture',
  attachments: [
    {
      id: 'image-1',
      url: 'asset:///notification-image.jpg',
    },
  ],
});
```

#### Propriétés des pièces jointes

| Propriété | Description                                               |
| --------- | --------------------------------------------------------- |
| `id`      | Identifiant unique                                        |
| `url`     | URL du contenu utilisant le protocole asset:// ou file:// |

Note : testez les pièces jointes sur vos plateformes cibles pour vérifier leur compatibilité.

### Channels

Les channels organisent les notifications en catégories avec des comportements différents. Bien qu'ils soient principalement utilisés sur Android, ils fournissent une API cohérente entre les plateformes.

#### Créer un channel

```javascript
import {
  createChannel,
  Importance,
  Visibility,
} from '@tauri-apps/plugin-notification';

await createChannel({
  id: 'messages',
  name: 'Messages',
  description: 'Notifications for new messages',
  importance: Importance.High,
  visibility: Visibility.Private,
  lights: true,
  lightColor: '#ff0000',
  vibration: true,
  sound: 'notification_sound',
});
```

#### Propriétés des channels

| Propriété     | Description                                            |
| ------------- | ------------------------------------------------------ |
| `id`          | Identifiant unique                                     |
| `name`        | Nom affiché                                            |
| `description` | Description de l'objectif                              |
| `importance`  | Niveau de priorité (None, Min, Low, Default, High)     |
| `visibility`  | Paramètre de confidentialité (Secret, Private, Public) |
| `lights`      | Active la LED de notification (Android)                |
| `lightColor`  | Couleur de la LED (Android)                            |
| `vibration`   | Active les vibrations                                  |
| `sound`       | Nom de fichier du son personnalisé                     |

#### Gérer les channels

Lister les channels existants :

```javascript
import { channels } from '@tauri-apps/plugin-notification';

const existingChannels = await channels();
```

Supprimer un channel :

```javascript
import { removeChannel } from '@tauri-apps/plugin-notification';

await removeChannel('messages');
```

#### Utiliser les channels

Envoyer une notification avec un channel :

```javascript
import { sendNotification } from '@tauri-apps/plugin-notification';

sendNotification({
  title: 'New Message',
  body: 'You have a new message',
  channelId: 'messages',
});
```

Note : créez les channels avant d'envoyer les notifications qui les référencent. Les identifiants de channel invalides empêchent l'affichage des notifications.
