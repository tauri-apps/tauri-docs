### Linux

Tauri nécessite plusieurs dépendances système pour le développement sous Linux. Elles peuvent varier selon votre distribution, mais nous avons inclus quelques distributions populaires ci-dessous pour vous aider à configurer votre environnement.

<Tabs syncKey="distro">
  <TabItem label="Debian">

```sh
sudo apt update
sudo apt install libwebkit2gtk-4.1-dev \
  build-essential \
  curl \
  wget \
  file \
  libxdo-dev \
  libssl-dev \
  libayatana-appindicator3-dev \
  librsvg2-dev
```

  </TabItem>
  <TabItem label="Arch">

```sh
sudo pacman -Syu
sudo pacman -S --needed \

  file \
  openssl \
  appmenu-gtk-module \
  libappindicator-gtk3 \
  librsvg \
  xdotool
```

  </TabItem>
  <TabItem label="Fedora">

  <TabItem label="openSUSE">

  <TabItem label="Alpine">
```sh
sudo apk add \
  build-base \
  webkit2gtk-4.1-dev \
  curl \
  wget \
  file \
  openssl \
  libayatana-appindicator-dev \
  librsvg
```

> Note : les conteneurs Alpine Linux n'incluent aucune police par défaut. Pour garantir que le texte s'affiche correctement dans votre app Tauri, installez au moins un paquet de police, par exemple `font-dejavu`.

> Note : Alpine cible la bibliothèque C musl. Les builds Rust lient donc statiquement plusieurs bibliothèques système. Si `cargo` ou `pnpm tauri build` échoue avec des erreurs d'édition de liens pour des symboles venant de bibliothèques que `pkg-config` signale comme présentes, installez les paquets `*-static` correspondants en plus des paquets `-dev` ci-dessus :
>
> ```sh
> sudo apk add --no-cache \
>   openssl-libs-static \
>   cairo-static \
>   harfbuzz-static \
>   glib-static \
>   wayland-static \
>   zlib-static
> ```
>
> Toutes les dépendances utilisées par Tauri ne sont pas forcément empaquetées en `*-static` sur Alpine. Dans ces cas, vous devrez peut-être compiler la bibliothèque statique manquante depuis les sources.

  </TabItem>

:::

### macOS

Tauri utilise [Xcode](https://developer.apple.com/xcode/resources/) et plusieurs dépendances de développement macOS et iOS.

Téléchargez et installez Xcode depuis l'un des emplacements suivants :

- [Mac App Store](https://apps.apple.com/gb/app/xcode/id497799835?mt=12)
- [site Apple Developer](https://developer.apple.com/xcode/resources/).

Veillez à lancer Xcode après l'installation afin qu'il puisse terminer sa configuration.

<details>
<summary>Vous développez uniquement pour des cibles desktop ?</summary>
Si vous prévoyez uniquement de développer des apps desktop sans cibler iOS, vous pouvez installer Xcode Command Line Tools à la place :

```sh
xcode-select --install
```

</details>

Suivant : [installer Rust](#rust)

### Windows

Tauri utilise Microsoft C++ Build Tools pour le développement, ainsi que Microsoft Edge WebView2. Les deux sont requis pour le développement sous Windows.

Suivez les étapes ci-dessous pour installer les dépendances requises.

#### Microsoft C++ Build Tools

1. Téléchargez l'installateur [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) et ouvrez-le pour commencer l'installation.
2. Pendant l'installation, cochez l'option « Desktop development with C++ ».

![Capture d'écran de l'installateur Visual Studio C++ Build Tools](@assets/start/prerequisites/visual-studio-build-tools-installer.png)

Suivant : [installer WebView2](#webview2).

#### WebView2

:::tip
WebView 2 est déjà installé sur Windows 10 (à partir de la version 1803) et les versions ultérieures de Windows. Si vous développez sur l'une de ces versions, vous pouvez ignorer cette étape et passer directement à [l'installation de Rust](#rust).
:::

Tauri utilise Microsoft Edge WebView2 pour afficher le contenu sous Windows.

Installez WebView2 en consultant la [section de téléchargement du runtime WebView2](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section). Téléchargez « Evergreen Bootstrapper » et installez-le.

Suivant : [vérifier VBSCRIPT](#vbscript-for-msi-installers)

<a id="vbscript-for-msi-installers"></a>

#### VBSCRIPT (pour les installateurs MSI)

:::note[Création de paquets MSI uniquement]
Cette étape est requise uniquement si vous prévoyez de créer des paquets d'installation MSI (`"targets": "msi"` ou `"targets": "all"` dans `tauri.conf.json`).
:::

La création de paquets MSI sous Windows nécessite que la fonctionnalité facultative VBSCRIPT soit activée. Cette fonctionnalité est activée par défaut sur la plupart des installations Windows, mais elle peut avoir été désactivée sur certains systèmes.

Si vous rencontrez des erreurs comme `failed to run light.exe` lors de la création de paquets MSI, vous devrez peut-être activer la fonctionnalité VBSCRIPT :

1. Ouvrez **Paramètres** → **Applications** → **Fonctionnalités facultatives** → **Plus de fonctionnalités Windows**
2. Repérez **VBSCRIPT** dans la liste et vérifiez qu'il est coché
3. Cliquez sur **Suivant** et redémarrez votre ordinateur si cela vous est demandé

**Note :** VBSCRIPT est actuellement activé par défaut sur la plupart des installations Windows, mais il est [en cours d'obsolescence](https://techcommunity.microsoft.com/blog/windows-itpro-blog/vbscript-deprecation-timelines-and-next-steps/4148301) et pourrait être désactivé dans de futures versions de Windows.

Suivant : [installer Rust](#rust)

## Rust

Tauri est construit avec [Rust](https://www.rust-lang.org) et en a besoin pour le développement. Installez Rust avec l'une des méthodes suivantes. Vous trouverez d'autres méthodes d'installation sur https://www.rust-lang.org/tools/install.

<Tabs syncKey="OS">
  <TabItem label="Linux et macOS" class="content">

Installez via [`rustup`](https://github.com/rust-lang/rustup) avec la commande suivante :

```sh
curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh
```

:::tip[Astuce de sécurité]
Nous avons audité ce script bash, et il fait ce qu'il indique faire. Néanmoins, avant d'exécuter aveuglément un script téléchargé avec curl, il est toujours sage de le lire d'abord.

Voici le fichier sous forme de script brut : [rustup.sh](https://sh.rustup.rs/)
:::

  </TabItem>
  <TabItem label="Windows">

Consultez https://www.rust-lang.org/tools/install pour installer `rustup`.

Vous pouvez aussi utiliser `winget` pour installer rustup avec la commande suivante dans PowerShell :

```powershell
winget install --id Rustlang.Rustup
```

:::caution[Chaîne d'outils MSVC par défaut]

Pour une prise en charge complète de Tauri et d'outils comme [`trunk`](https://trunk-rs.github.io/trunk/), assurez-vous que la chaîne d'outils Rust MSVC est le `default host triple` sélectionné dans la boîte de dialogue de l'installateur. Selon votre système, il devrait s'agir de `x86_64-pc-windows-msvc`, `i686-pc-windows-msvc` ou `aarch64-pc-windows-msvc`.

Si Rust est déjà installé, vous pouvez vérifier que la bonne chaîne d'outils est installée en exécutant cette commande :

```powershell
rustup default stable-msvc
```

:::

  </TabItem>
</Tabs>

**Veillez à redémarrer votre terminal, et dans certains cas votre système, pour que les changements prennent effet.**

Suivant : [configurer les cibles mobiles](#configure-for-mobile-targets) si vous souhaitez compiler pour Android et iOS, ou, si vous voulez utiliser un framework JavaScript, [installer Node](#nodejs). Sinon, [créez un projet](/start/create-project/).

## Node.js

:::note[Écosystème JavaScript]
Uniquement si vous prévoyez d'utiliser un framework frontend JavaScript
:::

1. Rendez-vous sur le [site de Node.js](https://nodejs.org), téléchargez la version Long Term Support (LTS) et installez-la.
2. Vérifiez que Node a été installé avec succès en exécutant :

```sh
node -v
# v20.10.0
npm -v
# 10.2.3
```

Il est important de redémarrer votre terminal pour qu'il reconnaisse la nouvelle installation. Dans certains cas, vous devrez peut-être redémarrer votre ordinateur.

Bien que npm soit le gestionnaire de paquets par défaut de Node.js, vous pouvez aussi en utiliser d'autres comme pnpm ou yarn. Pour les activer, exécutez `corepack enable` dans votre terminal. Cette étape est facultative et n'est nécessaire que si vous préférez utiliser un gestionnaire de paquets autre que npm.

Suivant : [configurer les cibles mobiles](#configure-for-mobile-targets) ou [créer un projet](/start/create-project/).

## Configurer les cibles mobiles

Si vous souhaitez cibler Android ou iOS avec votre app, vous devez installer quelques dépendances supplémentaires :

- [Android](#android)
- [iOS](#ios)

### Android

1. Téléchargez et installez [Android Studio depuis le site Android Developers](https://developer.android.com/studio)
2. Définissez la variable d'environnement `JAVA_HOME` :

{/* TODO: Can this be done in the 4th step? */}

<Tabs syncKey="prereqs">
<TabItem label="Linux">

```sh
export JAVA_HOME=/opt/android-studio/jbr
```

</TabItem>
<TabItem label="macOS">

```sh
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
```

</TabItem>
<TabItem label="Windows">

```ps
[System.Environment]::SetEnvironmentVariable("JAVA_HOME", "C:\Program Files\Android\Android Studio\jbr", "User")
```

</TabItem>
</Tabs>
3. Utilisez le SDK Manager dans Android Studio pour installer les éléments suivants :

- Android SDK Platform
- Android SDK Platform-Tools
- NDK (Side by side)
- Android SDK Build-Tools
- Android SDK Command-line Tools

Sélectionner « Show Package Details » dans le SDK Manager permet d'installer d'anciennes versions des paquets. N'installez d'anciennes versions que si nécessaire, car elles peuvent introduire des problèmes de compatibilité ou des risques de sécurité.

4. Définissez les variables d'environnement `ANDROID_HOME` et `NDK_HOME`.

<Tabs syncKey="prereqs">
<TabItem label="Linux">

```sh
export ANDROID_HOME="$HOME/Android/Sdk"
export NDK_HOME="$ANDROID_HOME/ndk/$(ls -1 $ANDROID_HOME/ndk)"
```

</TabItem>
<TabItem label="macOS">

```sh
export ANDROID_HOME="$HOME/Library/Android/sdk"
export NDK_HOME="$ANDROID_HOME/ndk/$(ls -1 $ANDROID_HOME/ndk)"
```

</TabItem>
<TabItem label="Windows">

```ps
[System.Environment]::SetEnvironmentVariable("ANDROID_HOME", "$env:LocalAppData\Android\Sdk", "User")
$VERSION = Get-ChildItem -Name "$env:LocalAppData\Android\Sdk\ndk" | Select-Object -Last 1
[System.Environment]::SetEnvironmentVariable("NDK_HOME", "$env:LocalAppData\Android\Sdk\ndk\$VERSION", "User")
```

:::tip
La plupart des apps ne rechargent pas automatiquement leurs variables d'environnement. Pour qu'elles prennent en compte les changements, vous pouvez redémarrer votre terminal et votre IDE ou, pour votre session PowerShell actuelle, la rafraîchir avec :

```ps
[System.Environment]::GetEnvironmentVariables("User").GetEnumerator() | % { Set-Item -Path "Env:\$($_.key)" -Value $_.value }
```

:::

</TabItem>

</Tabs>

5. Ajoutez les cibles Android avec `rustup` :

```sh
rustup target add aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android
```

Suivant : [configurer iOS](#ios) ou [créer un projet](/start/create-project/).

### iOS

:::caution[macOS uniquement]
Le développement iOS nécessite Xcode et n'est disponible que sur macOS. Assurez-vous d'avoir installé Xcode, et non Xcode Command Line Tools, dans la section des [dépendances système macOS](#macos).
:::

1. Ajoutez les cibles iOS avec `rustup` dans le terminal :

```sh
rustup target add aarch64-apple-ios x86_64-apple-ios aarch64-apple-ios-sim
```

2. Installez [Homebrew](https://brew.sh) :

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

3. Installez [Cocoapods](https://cocoapods.org) avec Homebrew :

```sh
brew install cocoapods
```

Suivant : [créer un projet](/start/create-project/).
