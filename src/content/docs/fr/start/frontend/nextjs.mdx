Next.js est un méta-framework pour React. Pour en savoir plus sur Next.js, consultez https://nextjs.org. Ce guide est exact pour Next.js 14.2.3.

## Liste de contrôle

- Utilisez des exports statiques en définissant `output: 'export'`. Tauri ne prend pas en charge les solutions basées sur un serveur.
- Utilisez le répertoire `out` comme `frontendDist` dans `tauri.conf.json`.

2.  ##### Mettre à jour la configuration de Next.js

    ```ts
    // next.config.mjs
    const isProd = process.env.NODE_ENV === 'production';

    const internalHost = process.env.TAURI_DEV_HOST || 'localhost';

    /** @type {import('next').NextConfig} */
    const nextConfig = {
      // Ensure Next.js uses SSG instead of SSR
      // https://nextjs.org/docs/pages/building-your-application/deploying/static-exports
      output: 'export',
      // Note: This feature is required to use the Next.js Image component in SSG mode.
      // See https://nextjs.org/docs/messages/export-image-api for different workarounds.
      images: {
        unoptimized: true,
      },
      // Configure assetPrefix or else the server won't properly resolve your assets.
      assetPrefix: isProd ? undefined : `http://${internalHost}:3000`,
    };

    export default nextConfig;
    ```

3.  ##### Mettre à jour la configuration de package.json

        ```json
        "scripts": {
          "dev": "next dev",
          "build": "next build",
          "start": "next start",
          "lint": "next lint",
          "tauri": "tauri"
        }
        ```
