Trunk est un bundler d'applications web WASM pour Rust. Apprenez-en plus sur Trunk sur https://trunk-rs.github.io/trunk/. Ce guide est valable pour Trunk 0.17.5.

## Liste de contrôle

- Utilisez SSG, Tauri ne prend pas officiellement en charge les solutions basées sur un serveur.
- Utilisez `serve.ws_protocol = "ws"` pour que le websocket de rechargement à chaud puisse se connecter correctement pendant le développement mobile.
- Activez `withGlobalTauri` pour vous assurer que les API Tauri sont disponibles dans la variable `window.__TAURI__` et peuvent être importées avec `wasm-bindgen`.

## Exemple de configuration

<Steps>

1. ##### Mettre à jour la configuration Tauri

   ```json
   // tauri.conf.json
   {
     "build": {
       "beforeDevCommand": "trunk serve",
       "beforeBuildCommand": "trunk build",
       "devUrl": "http://localhost:8080",
       "frontendDist": "../dist"
     },
     "app": {
       "withGlobalTauri": true
     }
   }
   ```

1. ##### Mettre à jour la configuration Trunk

   ```toml
   # Trunk.toml
   [watch]
   ignore = ["./src-tauri"]

   [serve]
   ws_protocol = "ws"
   ```

</Steps>
