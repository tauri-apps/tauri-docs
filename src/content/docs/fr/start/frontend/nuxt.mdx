Nuxt est un méta-framework pour Vue. Pour en savoir plus sur Nuxt, consultez https://nuxt.com. Ce guide est exact pour Nuxt 4.2.

## Liste de contrôle

- Utilisez SSG en définissant `ssr: false`. Tauri ne prend pas en charge les solutions basées sur un serveur.
- Utilisez la valeur par défaut `../dist` comme `frontendDist` dans `tauri.conf.json`.
- Compilez avec `nuxi build`.
- (Optionnel) Désactivez la télémétrie en définissant `telemetry: false` dans `nuxt.config.ts`.

1.  ##### Mettre à jour la configuration de Nuxt

    ```ts
    export default defineNuxtConfig({
      compatibilityDate: '2025-05-15',
      // (optional) Enable the Nuxt devtools
      devtools: { enabled: true },
      // Enable SSG
      ssr: false,
      // Enables the development server to be discoverable by other devices when running on iOS physical devices
      devServer: {
        host: '0',
      },
      vite: {
        // Better support for Tauri CLI output
        clearScreen: false,
        // Enable environment variables
        // Additional environment variables can be found at
        // https://v2.tauri.app/reference/environment-variables/
        envPrefix: ['VITE_', 'TAURI_'],
        server: {
          // Tauri requires a consistent port
          strictPort: true,
        },
      },
      // Avoids error [unhandledRejection] EMFILE: too many open files, watch
      ignore: ['**/src-tauri/**'],
    });
    ```
