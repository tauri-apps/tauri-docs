Nous, les mainteneurs, sommes vraiment heureux que vous souhaitiez contribuer à Tauri. Nous accueillons les contributeurs de tous niveaux et sommes ravis de fournir des conseils sur les PRs.
En cas de doute, vous pouvez nous contacter sur [notre serveur Discord](https://discord.gg/SpmNs4S).

### Dépôts du projet

Les principaux dépôts Tauri auxquels vous pouvez contribuer sont :

- Le dépôt [core Tauri](https://github.com/tauri-apps/tauri/), qui contient le runtime Tauri, les outils de build, les macros et les utilitaires.
- Le dépôt [Plugins workspace](https://github.com/tauri-apps/plugins-workspace), qui contient tous les plugins Tauri officiels.
- Le dépôt [Tauri Docs](https://github.com/tauri-apps/tauri-docs), qui contient ce site web.

Chacun de ces dépôts Tauri contient un fichier `.github/CONTRIBUTING.md`. Vous y trouverez des instructions pour configurer l'environnement de développement local et soumettre une Pull Request.

### Traduire

La documentation Tauri est disponible en plusieurs langues : anglais, français, espagnol, chinois simplifié, japonais et coréen. Les contributions aux traductions sont les bienvenues.

Lorsque vous traduisez ou relisez la documentation, envisagez d'utiliser les outils suivants :

- **zhlint** : un outil de lint pour le texte chinois qui vérifie la ponctuation, les espaces et d'autres problèmes courants. Recommandé pour les contributeurs travaillant sur la locale `zh-cn`. Disponible sur [zhlint.jinjiang.dev](https://zhlint.jinjiang.dev/).
- **Chinese Copywriting Guidelines** : un guide de style pour rédiger un texte chinois cohérent et correct. Disponible sur [github.com/sparanoid/chinese-copywriting-guidelines](https://github.com/sparanoid/chinese-copywriting-guidelines).
- **Extension VS Code Starlight i18n** : une extension utile pour gérer le contenu i18n dans les sites de documentation basés sur Starlight. Disponible sur le [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=hideoo.starlight-i18n).
