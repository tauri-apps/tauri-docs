Cette politique de marque a été préparée pour vous aider à comprendre comment utiliser les marques commerciales, marques de service et logos TAURI détenus par le Tauri Programme au sein de la Commons Conservancy.

Même si notre logiciel est disponible sous une licence logicielle libre et open source, cette licence de copyright n'inclut pas de licence d'utilisation de notre marque. Cette politique vise à expliquer comment utiliser nos marques conformément au droit applicable et aux attentes de la communauté.

**Cette politique couvre :**

- Nos marques verbales et marques de service : TAURI, TAO, WRY
- Nos logos : les logos TAURI, TAO, WRY (et tous leurs dérivés visuels)

Cette politique englobe toutes les marques commerciales et marques de service, qu'elles soient enregistrées ou non.

## Règles générales

Chaque fois que vous utilisez l'une de nos marques, vous devez toujours le faire d'une manière qui ne trompe personne sur ce qui est fourni et par qui. Par exemple, vous ne pouvez pas dire que vous distribuez le logiciel TAURI si vous distribuez une version modifiée de celui-ci, c'est-à-dire un fork, car les destinataires pourraient ne pas comprendre les différences entre vos versions modifiées et les nôtres.

Vous ne pouvez pas non plus utiliser notre logo sur votre site web d'une manière qui suggère que votre site est un site officiel ou que nous l'approuvons.

Vous pouvez en revanche dire que vous aimez le logiciel TAURI, que vous participez à la communauté TAURI, ou que vous fournissez une version non modifiée du logiciel TAURI.

Vous ne pouvez pas utiliser ni enregistrer nos marques, ou des variantes de celles-ci, comme partie de votre propre marque commerciale, marque de service, nom de domaine, nom d'entreprise, nom commercial, nom de produit ou nom de service.

Le droit des marques n'autorise pas l'utilisation de noms ou de marques trop similaires aux nôtres. Vous ne pouvez donc pas utiliser une variante évidente de l'une de nos marques, ni un équivalent phonétique, un équivalent en langue étrangère, une imitation ou une abréviation pour un produit ou service similaire ou compatible. Nous considérerions les exemples suivants comme trop similaires à l'une de nos marques :

- TAURIMAGE
- Tauri Wallet App

## Utilisations acceptables

### Applications

TAURI est un framework permettant de créer des applications pour appareils informatiques. Vous pouvez indiquer que votre application utilise TAURI, mais vous devez veiller à ne pas donner l'impression que votre application est approuvée par The Tauri Programme within the Commons Conservancy, ou qu'il s'agit d'une application officielle. Vous devez faire attention à ne pas distribuer votre application avec l'ICÔNE par défaut.

### Plugins et modèles

Vous pouvez publier le code de plugins et de modèles en utilisant les conventions de nommage appropriées, mais veuillez indiquer que ces travaux ne sont pas officiellement approuvés. Seules les bases de code gérées par l'organisation dans l'organisation GitHub `tauri-apps` sont considérées comme officielles.

## Modifications du cœur (forks)

Si vous distribuez une version modifiée de notre logiciel (TAURI CORE), vous devez en retirer tous nos logos et noms. Vous devez conserver notre licence d'origine au format SPDX. Vous pouvez utiliser nos marques verbales, mais pas nos logos, pour décrire honnêtement l'origine du logiciel que vous fournissez. Par exemple, si le code que vous distribuez est une modification de notre logiciel, vous pouvez dire : « Ce logiciel est dérivé du code source du logiciel TAURI. »

### Déclarations de compatibilité

Vous pouvez utiliser les marques verbales, mais pas les logos, pour décrire honnêtement la relation entre votre logiciel et le nôtre. Toute autre utilisation peut laisser entendre que nous avons certifié ou approuvé votre logiciel. Si vous souhaitez utiliser nos logos, veuillez nous contacter pour discuter des conditions de licence.

### Nommer des produits compatibles

Si vous souhaitez décrire votre produit en faisant référence au logiciel TAURI, voici les conditions dans lesquelles vous pouvez le faire. Vous pouvez appeler votre logiciel XYZ (où XYZ est le nom de votre produit) pour TAURI uniquement si :

- Toutes les versions du logiciel TAURI que vous livrez avec votre produit sont les binaires exacts fournis par nous, ou fabriqués par le logiciel cœur et les outils que nous fournissons.
- Votre produit est entièrement compatible avec les API du logiciel TAURI.
- Vous utilisez la mention suivante dans les supports marketing ou les descriptions de produit : « TAURI is a trademark of The Tauri Programme within the Commons Conservancy. https://tauri.app/ »

### Groupes d'utilisateurs

Vous pouvez utiliser les marques verbales dans le nom de votre groupe d'utilisateurs à condition que :

- L'objet principal du groupe soit notre logiciel
- Le groupe ne réalise pas de bénéfice
- Toute participation financière demandée pour assister aux réunions serve uniquement à couvrir le coût du lieu, de la nourriture et des boissons

Vous n'êtes pas autorisé à organiser une conférence en utilisant nos marques.

### Pas de noms de domaine

Vous ne devez enregistrer aucun domaine incluant nos marques verbales, ni aucune variante ou combinaison de celles-ci.

### Autres usages lucratifs des marques TAURI

Si vous créez une vidéo, une série de tutoriels, un livre ou tout autre matériel pédagogique pour lequel vous recevez un paiement via des abonnements, des ventes, de la publicité ou un mécanisme similaire, vous devez obtenir une autorisation de licence explicite de The Tauri Programme within the Commons Conservancy.

## Comment afficher nos marques

Lorsque vous avez le droit d'utiliser notre marque, voici comment l'afficher.

### Marquage des marques et mentions

La première mention, ou la mention la plus visible, d'une marque sur une page web, un document ou une documentation doit être accompagnée d'un symbole indiquant si la marque est une marque déposée (« ® ») ou une marque non déposée (« ™ »). Si vous ne savez pas lequel s'applique, contactez-nous. (TAURI elle-même est une marque déposée.)

Placez la mention suivante au bas de la page où vous avez utilisé la marque : TAURI is trademark of [The Tauri Programme within the Commons Conservancy].”

### Utilisation des marques dans le texte

Utilisez toujours les marques dans leur forme exacte, avec l'orthographe correcte, sans les abréger, les couper par un trait d'union ou les combiner avec un autre mot ou d'autres mots.

- Inacceptable : TAUREE
- Acceptable : TAURI

Ne mettez pas une marque au pluriel.

- Inacceptable : I have seventeen TAURIs running on my computer.
- Acceptable : I am running seventeen TAURI applications on my computer and have ram to spare.

Utilisez toujours une marque comme adjectif modifiant un nom.

- Inacceptable : This is a TAURI.
- Acceptable : This is a TAURI software application.

### Utilisation des logos

Vous ne pouvez modifier aucun logo, sauf pour le redimensionner. Cela signifie que vous ne pouvez pas ajouter d'éléments décoratifs, changer les couleurs, changer les proportions, le déformer, ajouter des éléments ou le combiner avec d'autres logos.

Nous disposons d'une version à contraste élevé du logo, que vous pouvez télécharger ci-dessous dans la section des ressources.
