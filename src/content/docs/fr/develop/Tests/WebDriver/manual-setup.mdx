Cette page couvre le pilotage direct de [`tauri-driver`], sans [`@wdio/tauri-service`]. Utilisez-la si vous n'utilisez pas
Node.js, si vous préférez [Selenium], ou si vous intégrez WebDriver dans un harnais de test personnalisé. Pour la plupart des projets, le service
est la voie la plus simple : il automatise tout ce qui suit et prend aussi en charge macOS. Consultez la [vue d'ensemble WebDriver] pour
commencer avec lui.

Lorsque vous pilotez `tauri-driver` directement, seuls Windows et Linux sont pris en charge sur desktop, car macOS ne dispose d'aucun outil
driver WKWebView. iOS et Android fonctionnent via Appium 2, mais le processus n'est actuellement pas simplifié.

## Dépendances système

Installez le dernier [`tauri-driver`] ou mettez à jour une installation existante avec :

```shell
cargo install tauri-driver --locked
```

Comme nous utilisons actuellement le serveur [WebDriver] natif de la plateforme, certaines exigences s'appliquent pour exécuter
[`tauri-driver`] sur les plateformes prises en charge.

### Linux

Nous utilisons `WebKitWebDriver` sur les plateformes Linux. Vérifiez si ce binaire existe déjà en exécutant `which WebKitWebDriver`, car
certaines distributions le fournissent avec le package WebKit classique. D'autres plateformes peuvent avoir un package séparé,
comme `webkit2gtk-driver` sur les distributions basées sur Debian.

### Windows

Assurez-vous de récupérer la version de [Microsoft Edge Driver] qui correspond à la version de Windows Edge utilisée pour construire et tester l'application.
Ce devrait presque toujours être la dernière version stable sur des installations Windows à jour. Si les deux versions ne correspondent pas, votre suite
de tests WebDriver peut se bloquer en essayant de se connecter.

Vous pouvez utiliser [msedgedriver-tool](https://github.com/chippers/msedgedriver-tool) pour télécharger le Microsoft Edge Driver approprié :

```powershell
cargo install --git https://github.com/chippers/msedgedriver-tool
& "$HOME/.cargo/bin/msedgedriver-tool.exe"
```

Le téléchargement contient un binaire appelé `msedgedriver.exe`. [`tauri-driver`] cherche ce binaire dans `$PATH`, donc assurez-vous
qu'il est disponible dans le path ou utilisez l'option `--native-driver` de [`tauri-driver`]. Vous pouvez vouloir le télécharger automatiquement dans le processus de configuration CI afin que les versions d'Edge et d'Edge Driver
restent synchronisées sur les machines CI Windows. Un guide sur ce sujet pourra être ajouté plus tard.
