# Publier dans l'Arch User Repository

## Configuration

Allez d'abord sur `https://aur.archlinux.org` et créez un compte. Assurez-vous d'ajouter les bonnes clés SSH. Ensuite, clonez un dépôt git vide avec cette commande.

```sh
git clone https://aur.archlinux.org/your-repo-name
```

Après avoir terminé les étapes ci-dessus, créez un fichier nommé `PKGBUILD`. Une fois le fichier créé, vous pouvez passer à l'étape suivante.

### Écrire un fichier PKGBUILD

```ini title="PKGBUILD"
pkgname=<pkgname>
pkgver=1.0.0
pkgrel=1
pkgdesc="Description of your app"
arch=('x86_64' 'aarch64')
url="https://github.com/<user>/<project>"
license=('MIT')
depends=('cairo' 'desktop-file-utils' 'gdk-pixbuf2' 'glib2' 'gtk3' 'hicolor-icon-theme' 'libsoup' 'pango' 'webkit2gtk-4.1')
options=('!strip' '!emptydirs')
install=${pkgname}.install
source_x86_64=("${url}/releases/download/v${pkgver}/appname_${pkgver}_amd64.deb")
source_aarch64=("${url}/releases/download/v${pkgver}/appname_${pkgver}_arm64.deb")
```

- En haut du fichier, définissez le nom de votre paquet et assignez-le à la variable `pkgname`.
- Définissez votre variable `pkgver`. Il est généralement préférable d'utiliser cette variable dans la variable source pour faciliter la maintenance.
- La variable `pkgdesc` apparaît sur la page de votre dépôt AUR et indique aux visiteurs ce que fait votre app.
- La variable `arch` contrôle les architectures pouvant installer votre paquet.
- La variable `url`, bien qu'elle ne soit pas requise, aide votre paquet à paraître plus professionnel.
- La variable `install` indique le nom du script `.install` exécuté lorsque le paquet est installé, supprimé ou mis à jour.
- La variable `depends` inclut la liste des éléments requis pour exécuter votre app. Pour toute app Tauri, vous devez inclure toutes les dépendances affichées ci-dessus.
- La variable `source` est requise et définit l'emplacement de votre paquet upstream. Vous pouvez rendre un `source` propre à une architecture en ajoutant l'architecture à la fin du nom de variable.

### Générer `.SRCINFO`

Pour pousser votre dépôt vers l'AUR, vous devez générer un fichier `.SRCINFO`. Cela peut être fait avec cette commande.

```sh
makepkg --printsrcinfo > .SRCINFO
```

### Tester

Tester l'app est très simple. Il suffit d'exécuter `makepkg` dans le même répertoire que le fichier `PKGBUILD` et de vérifier que cela fonctionne.

### Publier

Enfin, une fois la phase de test terminée, vous pouvez publier l'application sur l'AUR (Arch User Repository) avec ces commandes.

```sh
git add .

git commit -m "Initial Commit"

git push
```

Si tout se passe bien, votre dépôt devrait maintenant apparaître sur le site de l'AUR.

## Exemples

### Extraire depuis un paquet Debian

```ini title="PKGBUILD"
# Maintainer:
# Contributor:
pkgname=<pkgname>
pkgver=1.0.0
pkgrel=1
pkgdesc="Description of your app"
arch=('x86_64' 'aarch64')
url="https://github.com/<user>/<project>"
license=('MIT')
depends=('cairo' 'desktop-file-utils' 'gdk-pixbuf2' 'glib2' 'gtk3' 'hicolor-icon-theme' 'libsoup' 'pango' 'webkit2gtk-4.1')
options=('!strip' '!debug')
install=${pkgname}.install
source_x86_64=("${url}/releases/download/v${pkgver}/appname_${pkgver}_amd64.deb")
source_aarch64=("${url}/releases/download/v${pkgver}/appname_${pkgver}_arm64.deb")
sha256sums_x86_64=('ca85f11732765bed78f93f55397b4b4cbb76685088553dad612c5062e3ec651f')
sha256sums_aarch64=('ed2dc3169d34d91188fb55d39867713856dd02a2360ffe0661cb2e19bd701c3c')
package() {
	# Extract package data
	tar -xvf data.tar.gz -C "${pkgdir}"

}
```

```ini title="my-tauri-app.install"
post_install() {
	gtk-update-icon-cache -q -t -f usr/share/icons/hicolor
	update-desktop-database -q
}

post_upgrade() {
	post_install
}

post_remove() {
	gtk-update-icon-cache -q -t -f usr/share/icons/hicolor
	update-desktop-database -q
}

```

### Construire depuis les sources

```ini title="PKGBUILD"
# Maintainer:
pkgname=<pkgname>-git
pkgver=<pkgver>
pkgrel=1
pkgdesc="Description of your app"
arch=('x86_64' 'aarch64')
url="https://github.com/<user>/<project>"
license=('MIT')
depends=('cairo' 'desktop-file-utils' 'gdk-pixbuf2' 'glib2' 'gtk3' 'hicolor-icon-theme' 'libsoup' 'pango' 'webkit2gtk-4.1')
makedepends=('git' 'openssl' 'appmenu-gtk-module' 'libappindicator-gtk3' 'librsvg' 'cargo' 'pnpm' 'nodejs')
provides=('<pkgname>')
conflicts=('<binname>' '<pkgname>')
source=("git+${url}.git")
sha256sums=('SKIP')

pkgver() {
	cd <project>
	( set -o pipefail
	  git describe --long --abbrev=7 2>/dev/null | sed 's/\([^-]*-g\)/r\1/;s/-/./g' ||
	  printf "r%s.%s" "$(git rev-list --count HEAD)" "$(git rev-parse --short=7 HEAD)"
	)
}

prepare() {
	cd <project>
	pnpm install
}

build() {
	cd <project>
	pnpm tauri build -b deb
}

package() {
	cp -a <project>/src-tauri/target/release/bundle/deb/<project>_${pkgver}_*/data/* "${pkgdir}"
}
```
