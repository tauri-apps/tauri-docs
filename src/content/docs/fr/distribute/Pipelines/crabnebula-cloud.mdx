## Distribuer avec CrabNebula Cloud

[CrabNebula](https://crabnebula.dev) est un partenaire officiel de Tauri qui fournit des services et outils pour les applications Tauri.
Le [CrabNebula Cloud](https://crabnebula.dev/cloud/) est une plateforme de distribution d'applications qui s'intègre facilement avec l'updater Tauri.

Le Cloud fournit un Content Delivery Network (CDN) capable de diffuser mondialement les installateurs et mises à jour de votre application tout en restant rentable et en exposant des métriques de téléchargement.

Avec le service CrabNebula Cloud, il est simple d'implémenter plusieurs canaux de release, des boutons de téléchargement pour le site web de votre application, et plus encore.

Configurer votre app Tauri pour utiliser le Cloud est simple : il suffit de vous connecter au [site Cloud] avec votre compte GitHub, de créer votre organisation et votre application, puis d'installer sa CLI pour créer une release et téléverser les bundles Tauri. Une [GitHub Action] est aussi fournie pour simplifier l'utilisation de la CLI dans les workflows GitHub.

Pour plus d'informations, consultez la [documentation CrabNebula Cloud].

[GitHub Action]: https://github.com/crabnebula-dev/cloud-release/
[site Cloud]: https://web.crabnebula.cloud/
[documentation CrabNebula Cloud]: https://docs.crabnebula.dev/cloud/
