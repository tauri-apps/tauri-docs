Tauri позволяет вашему приложению иметь CLI через [clap](https://github.com/clap-rs/clap), надёжный парсер аргументов командной строки. С помощью простого определения CLI в файле `tauri.conf.json` вы можете задать свой интерфейс и читать карту совпадений аргументов на JavaScript и/или Rust.

## Базовая конфигурация

В `tauri.conf.json` у вас есть следующая структура для настройки интерфейса:

```json title="src-tauri/tauri.conf.json"
{
  "plugins": {
    "cli": {
      "description": "Tauri CLI Plugin Example",
      "args": [
        {
          "short": "v",
          "name": "verbose",
          "description": "Verbosity level"
        }
      ],
      "subcommands": {
        "run": {
          "description": "Run the application",
          "args": [
            {
              "name": "debug",
              "description": "Run application in debug mode"
            },
            {
              "name": "release",
              "description": "Run application in release mode"
            }
          ]
        }
      }
    }
  }
}
```

:::note

Все JSON-конфигурации здесь — лишь примеры, многие другие поля опущены для наглядности.

:::

## Добавление аргументов

Массив `args` представляет список аргументов, принимаемых его командой или подкомандой.

{/* TODO: List available configuration */}

### Позиционные аргументы

Позиционный аргумент определяется своим положением в списке аргументов. При следующей конфигурации:

```json title="src-tauri/tauri.conf.json"
{
  "args": [
    {
      "name": "source",
      "index": 1,
      "takesValue": true
    },
    {
      "name": "destination",
      "index": 2,
      "takesValue": true
    }
  ]
}
```

Пользователи могут запускать ваше приложение как `./app tauri.txt dest.txt`, и карта совпадений аргументов определит `source` как `"tauri.txt"`, а `destination` как `"dest.txt"`.

### Именованные аргументы

Именованный аргумент — это пара (ключ, значение), где ключ идентифицирует значение. При следующей конфигурации:

```json title="tauri-src/tauri.conf.json"
{
  "args": [
    {
      "name": "type",
      "short": "t",
      "takesValue": true,
      "multiple": true,
      "possibleValues": ["foo", "bar"]
    }
  ]
}
```

Пользователи могут запускать ваше приложение как `./app --type foo bar`, `./app -t foo -t bar` или `./app --type=foo,bar`, и карта совпадений аргументов определит `type` как `["foo", "bar"]`.

### Аргументы-флаги

Аргумент-флаг — это отдельный ключ, чьё наличие или отсутствие предоставляет информацию вашему приложению. При следующей конфигурации:

```json title="tauri-src/tauri.conf.json"
{
  "args": [
    {
      "name": "verbose",
      "short": "v"
    }
  ]
}
```

Пользователи могут запускать ваше приложение как `./app -v -v -v`, `./app --verbose --verbose --verbose` или `./app -vvv`, и карта совпадений аргументов определит `verbose` как `true`, с `occurrences = 3`.

## Подкоманды

Некоторые CLI-приложения имеют дополнительные интерфейсы в виде подкоманд. Например, CLI `git` имеет `git branch`, `git commit` и `git push`. Вы можете определить дополнительные вложенные интерфейсы с помощью массива `subcommands`:

```json title="tauri-src/tauri.conf.json"
{
  "cli": {
    ...
    "subcommands": {
      "branch": {
        "args": []
      },
      "push": {
        "args": []
      }
    }
  }
}
```

Его конфигурация такая же, как у корневой конфигурации приложения, с полями `description`, `longDescription`, `args` и т.д.

## Использование

Плагин CLI доступен как в JavaScript, так и в Rust.

```javascript
import { getMatches } from '@tauri-apps/plugin-cli';
// when using `"withGlobalTauri": true`, you may use
// const { getMatches } = window.__TAURI__.cli;

const matches = await getMatches();
if (matches.subcommand?.name === 'run') {
  // `./your-app run $ARGS` was executed
  const args = matches.subcommand.matches.args;
  if (args.debug?.value === true) {
    // `./your-app run --debug` was executed
  }
  if (args.release?.value === true) {
    // `./your-app run --release` was executed
  }
}
```

```rust title="src-tauri/src/lib.rs" {1, 6-18}
use tauri_plugin_cli::CliExt;

#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
   tauri::Builder::default()
       .plugin(tauri_plugin_cli::init())
       .setup(|app| {
           match app.cli().matches() {
               // `matches` here is a Struct with { args, subcommand }.
               // `args` is `HashMap<String, ArgData>` where `ArgData` is a struct with { value, occurrences }.
               // `subcommand` is `Option<Box<SubcommandMatches>>` where `SubcommandMatches` is a struct with { name, matches }.
               Ok(matches) => {
                   println!("{:?}", matches)
               }
               Err(_) => {}
           }
           Ok(())
       })
       .run(tauri::generate_context!())
       .expect("error while running tauri application");
}
```

## Разрешения

По умолчанию все потенциально опасные команды и области действия плагина заблокированы и недоступны. Вы должны изменить разрешения в конфигурации `capabilities`, чтобы включить их.

См. [Обзор возможностей](/ru/security/capabilities/) для получения дополнительной информации и [пошаговое руководство](/ru/learn/security/using-plugin-permissions/) по использованию разрешений плагинов.

```json title="src-tauri/capabilities/default.json" ins={6}
{
  "$schema": "../gen/schemas/desktop-schema.json",
  "identifier": "main-capability",
  "description": "Capability for the main window",
  "windows": ["main"],
  "permissions": ["cli:default"]
}
```
