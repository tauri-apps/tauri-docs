## Установка

Установите плагин process, чтобы начать.

<Tabs>
    <TabItem label="Automatic">

    Используйте менеджер пакетов вашего проекта, чтобы добавить зависимость:

    <CommandTabs npm="npm run tauri add process"
    yarn="yarn run tauri add process"
    pnpm="pnpm tauri add process"
    deno="deno task tauri add process"
    bun="bun tauri add process"
    cargo="cargo tauri add process" />

    </TabItem>
    <TabItem label="Manual">
        <Steps>

        1. Выполните следующую команду в папке `src-tauri`, чтобы добавить плагин в зависимости проекта в `Cargo.toml`:

            ```sh frame=none
            cargo add tauri-plugin-process
            ```

        2.  Измените `lib.rs`, чтобы инициализировать плагин:

            ```rust title="src-tauri/src/lib.rs" ins={4}
            #[cfg_attr(mobile, tauri::mobile_entry_point)]
            pub fn run() {
                tauri::Builder::default()
                    .plugin(tauri_plugin_process::init())
                    .run(tauri::generate_context!())
                    .expect("error while running tauri application");
            }
            ```

        3.  Если вы хотите использовать плагин на JavaScript, установите также npm-пакет:

            <CommandTabs
                npm="npm install @tauri-apps/plugin-process"
                yarn="yarn add @tauri-apps/plugin-process"
                pnpm="pnpm add @tauri-apps/plugin-process"
                deno="deno add npm:@tauri-apps/plugin-process"
                bun="bun add @tauri-apps/plugin-process"
            />

        </Steps>
    </TabItem>

</Tabs>

## Использование

Плагин process доступен как в JavaScript, так и в Rust.

<Tabs syncKey="lang">
<TabItem label="JavaScript">

```javascript
import { exit, relaunch } from '@tauri-apps/plugin-process';
// when using `"withGlobalTauri": true`, you may use
// const { exit, relaunch } = window.__TAURI__.process;

// exits the app with the given status code
await exit(0);

// restarts the app
await relaunch();
```

</TabItem>
<TabItem label="Rust">

Обратите внимание, что `app` — это экземпляр [`AppHandle`](https://docs.rs/tauri/2.0.0/tauri/struct.AppHandle.html).

```rust
# let app: tauri::AppHandle = todo!();
// exits the app with the given status code
app.exit(0);

// restarts the app
app.restart();
```

</TabItem>
</Tabs>

## Разрешения

По умолчанию все потенциально опасные команды и области действия плагина заблокированы и недоступны. Вы должны изменить разрешения в конфигурации `capabilities`, чтобы включить их.

См. [Обзор возможностей](/ru/security/capabilities/) для получения дополнительной информации и [пошаговое руководство](/ru/learn/security/using-plugin-permissions/) по использованию разрешений плагинов.

```json title="src-tauri/capabilities/default.json" ins={4}
{
  "permissions": [
    ...,
    "process:default",
  ]
}
```
