## Установка

Установите плагин positioner, чтобы начать.

:::note
Если вы собираетесь перемещать окно только из кода Rust, вам нужна только зависимость в `src-tauri/Cargo.toml`, и вы можете удалить регистрацию плагина из `lib.rs`, если выберете автоматическую настройку.
:::

Для работы позиций относительно иконки в трее требуется дополнительная настройка.

<Steps>
	1. Добавьте возможность `tray-icon` в ваш файл `Cargo.toml`:
		```toml title="src-tauri/Cargo.toml" ins={2}
		[dependencies]
		tauri-plugin-positioner = { version = "2.0.0", features = ["tray-icon"] }
		```

    2. Настройте `on_tray_event` для плагина positioner:
    	```rust title="src-tauri/src/lib.rs" ins={4-12}
    	pub fn run() {
    		tauri::Builder::default()
    			// This is required to get tray-relative positions to work
    			.setup(|app| {
    					#[cfg(desktop)]
    					{
    						app.handle().plugin(tauri_plugin_positioner::init());
    							tauri::tray::TrayIconBuilder::new()
    								.on_tray_icon_event(|tray_handle, event| {
    									tauri_plugin_positioner::on_tray_event(tray_handle.app_handle(), &event);
    								})
    								.build(app)?;
    					}
    				Ok(())
    			})
    			.run(tauri::generate_context!())
    			.expect("error while running tauri application");
    	}
    	```

</Steps>

## Использование

API плагина доступны через JavaScript-привязки:

```javascript
import { moveWindow, Position } from '@tauri-apps/plugin-positioner';
// when using `"withGlobalTauri": true`, you may use
// const { moveWindow, Position } = window.__TAURI__.positioner;

moveWindow(Position.TopRight);
```

Вы можете импортировать и использовать расширение трейта Window непосредственно через Rust:

```rust
use tauri_plugin_positioner::{WindowExt, Position};

let mut win = app.get_webview_window("main").unwrap();
let _ = win.as_ref().window().move_window(Position::TopRight);
```

## Разрешения

По умолчанию все потенциально опасные команды и области действия плагина заблокированы и недоступны. Вы должны изменить разрешения в конфигурации `capabilities`, чтобы включить их.

См. [Обзор возможностей](/ru/security/capabilities/) для получения дополнительной информации и [пошаговое руководство](/ru/learn/security/using-plugin-permissions/) по использованию разрешений плагинов.

```json title="src-tauri/capabilities/default.json" ins={4}
{
  "permissions": [
    ...,
    "positioner:default",
  ]
}
```
