## Использование

После завершения процесса регистрации и настройки плагина вы можете получить доступ ко всем его API через JavaScript-привязки.

### Загрузка

`upload` отправляет файл как исходное тело запроса (не `multipart/form-data`) и возвращает тело ответа как текст:

```javascript
import { upload } from '@tauri-apps/plugin-upload';
// when using `"withGlobalTauri": true`, you may use
// const { upload } = window.__TAURI__.upload;

const response = await upload(
  'https://example.com/file-upload',
  '/path/to/my/file.txt',
  ({ progressTotal, total }) =>
    console.log(`Uploaded ${progressTotal} of ${total} bytes`), // a callback that will be called with the upload progress
  { 'Content-Type': 'text/plain' } // optional headers to send with the request
);
```

По умолчанию отправляется `POST`-запрос. Чтобы использовать `PUT` или `PATCH`, передайте `HttpMethod` пятым аргументом:

```javascript
import { upload, HttpMethod } from '@tauri-apps/plugin-upload';

await upload(
  'https://example.com/file-upload',
  '/path/to/my/file.txt',
  undefined, // no progress callback
  { 'Content-Type': 'text/plain' },
  HttpMethod.Put
);
```

### Скачивание

`download` сохраняет тело ответа по указанному пути к файлу:

```javascript
import { download } from '@tauri-apps/plugin-upload';
// when using `"withGlobalTauri": true`, you may use
// const { download } = window.__TAURI__.upload;

await download(
  'https://example.com/file-download-link',
  '/path/to/save/my/file.txt',
  ({ progressTotal, total }) =>
    console.log(`Downloaded ${progressTotal} of ${total} bytes`), // a callback that will be called with the download progress
  { Authorization: 'Bearer <token>' } // optional headers to send with the request
);
```

По умолчанию отправляется `GET`-запрос. Если вы передадите тело пятым аргументом, вместо этого будет отправлен `POST`-запрос с этим телом:

```javascript
import { download } from '@tauri-apps/plugin-upload';

await download(
  'https://example.com/export',
  '/path/to/save/report.csv',
  undefined, // no progress callback
  { 'Content-Type': 'application/json' },
  JSON.stringify({ format: 'csv' })
);
```

### Прогресс

Колбэк прогресса выполняется для каждого чанка и получает:

- `progress`: байты в последнем чанке, а не общий итог
- `progressTotal`: переданные на данный момент байты
- `total`: общий размер в байтах. Для скачиваний он берётся из заголовка `Content-Length` и равен `0`, если сервер его не отправляет.
- `transferSpeed`: приблизительная скорость в байтах в секунду

### Пути к файлам

Относительные пути разрешаются относительно рабочего каталога приложения, который отличается в `tauri dev` и в собранном приложении. Вместо этого используйте абсолютные пути, например с помощью [path API](/reference/javascript/api/namespacepath/):

```javascript
import { appDataDir, join } from '@tauri-apps/api/path';

const filePath = await join(await appDataDir(), 'file.txt');
```

При скачивании родительский каталог должен уже существовать, а любой существующий файл по этому пути перезаписывается. Если скачивание завершится неудачей, частичный файл не удаляется.

### Ошибки

Обе функции отклоняют промис, если файл не может быть прочитан или записан, запрос завершается неудачей или сервер возвращает статус ошибки.

## Разрешения

По умолчанию все потенциально опасные команды и области действия плагина заблокированы и недоступны. Вы должны изменить разрешения в конфигурации `capabilities`, чтобы включить их.

См. [Обзор возможностей](/ru/security/capabilities/) для получения дополнительной информации и [пошаговое руководство](/ru/learn/security/using-plugin-permissions/) по использованию разрешений плагинов.

```json title="src-tauri/capabilities/default.json" ins={4}
{
  "permissions": [
    ...,
    "upload:default",
  ]
}
```
