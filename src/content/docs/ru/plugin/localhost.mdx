Раскрывайте ресурсы вашего приложения через сервер localhost вместо пользовательского протокола по умолчанию.

:::caution
Этот плагин несёт значительные риски безопасности, и вы должны использовать его только в том случае, если знаете, что делаете. Если сомневаетесь, используйте реализацию пользовательского протокола по умолчанию.
:::

Установите плагин localhost, чтобы начать.

            ```rust title="src-tauri/src/lib.rs" ins={4}
                    .plugin(tauri_plugin_localhost::Builder::new(9527).build())
                    .run(tauri::generate_context!())
                    .expect("error while running tauri application");
            }
            ```

## Использование

Плагин localhost доступен на Rust.

```rust title="src-tauri/src/lib.rs" {4} {7-14}
use tauri::{webview::WebviewWindowBuilder, WebviewUrl};

pub fn run() {
  let port: u16 = 9527;

  tauri::Builder::default()
      .plugin(tauri_plugin_localhost::Builder::new(port).build())
      .setup(move |app| {
          let url = format!("http://localhost:{}", port).parse().unwrap();
          WebviewWindowBuilder::new(app, "main".to_string(), WebviewUrl::External(url))
              .title("Localhost Example")
              .build()?;
          Ok(())
      })
      .run(tauri::generate_context!())
      .expect("error while running tauri application");
}
```
