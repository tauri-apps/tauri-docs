## Использование

После добавления плагина window-state все окна будут запоминать своё состояние при закрытии приложения и восстанавливать предыдущее состояние при следующем запуске.

Вы также можете обращаться к плагину window-state как из JavaScript, так и из Rust.

:::tip
Восстановление состояния происходит после создания окна,
поэтому, чтобы предотвратить мигание окна, вы можете задать `visible` равным `false` при создании окна;
плагин покажет окно, когда восстановит состояние.
:::

### JavaScript

Вы можете использовать `saveWindowState`, чтобы вручную сохранить состояние окна:

```javascript
import { saveWindowState, StateFlags } from '@tauri-apps/plugin-window-state';
// when using `"withGlobalTauri": true`, you may use
// const { saveWindowState, StateFlags } = window.__TAURI__.windowState;

saveWindowState(StateFlags.ALL);
```

Аналогично вы можете вручную восстановить состояние окна с диска:

```javascript
import {
  restoreStateCurrent,
  StateFlags,
} from '@tauri-apps/plugin-window-state';
// when using `"withGlobalTauri": true`, you may use
// const { restoreStateCurrent, StateFlags } = window.__TAURI__.windowState;

restoreStateCurrent(StateFlags.ALL);
```

### Rust

Вы можете использовать метод `save_window_state()`, предоставляемый трейтом `AppHandleExt`:

```rust
use tauri_plugin_window_state::{AppHandleExt, StateFlags};

// `tauri::AppHandle` now has the following additional method
app.save_window_state(StateFlags::all()); // will save the state of all open windows to disk
```

Аналогично вы можете вручную восстановить состояние окна с диска с помощью метода `restore_state()`, предоставляемого трейтом `WindowExt`:

```rust
use tauri_plugin_window_state::{WindowExt, StateFlags};

// all `Window` types now have the following additional method
window.restore_state(StateFlags::all()); // will restore the window's state from disk
```

## Разрешения

По умолчанию все потенциально опасные команды и области действия плагина заблокированы и недоступны. Вы должны изменить разрешения в конфигурации `capabilities`, чтобы включить их.

См. [Обзор возможностей](/ru/security/capabilities/) для получения дополнительной информации и [пошаговое руководство](/ru/learn/security/using-plugin-permissions/) по использованию разрешений плагинов.

```json title="src-tauri/capabilities/default.json" ins={4}
{
  "permissions": [
    ...,
    "window-state:default",
  ]
}
```
