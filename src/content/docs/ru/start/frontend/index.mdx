Tauri не зависит от конкретного фронтенда и из коробки поддерживает большинство фронтенд-фреймворков. Однако иногда фреймворку требуется немного дополнительной настройки для интеграции с Tauri. Ниже приведён список фреймворков и их рекомендуемые конфигурации.

Если какой-либо фреймворк не указан в списке, он может работать с Tauri без дополнительной настройки или просто ещё не задокументирован. Приветствуются любые предложения по добавлению фреймворка, которому может потребоваться дополнительная настройка, чтобы помочь другим участникам сообщества Tauri.

## Контрольный список конфигурации

Концептуально Tauri действует как статический веб-хост. Вам нужно предоставить Tauri папку с набором HTML, CSS, JavaScript и, возможно, WASM, которые могут быть обслужены WebView, предоставляемым Tauri.

- Используйте генерацию статических сайтов (SSG), одностраничные приложения (SPA) или классические многостраничные приложения (MPA). Tauri не поддерживает нативно серверные альтернативы (такие как SSR).
- Для мобильной разработки необходим сервер разработки какого-либо рода, который может размещать фронтенд на вашем внутреннем IP-адресе.
- Используйте правильную связь «клиент—сервер» между вашим приложением и API (без гибридных решений с SSR).
