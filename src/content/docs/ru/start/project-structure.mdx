Проект Tauri обычно состоит из двух частей — проекта на Rust и проекта на JavaScript (необязательно), и типично настройка выглядит примерно так:

```
.
├── package.json
├── index.html
├── src/
│   ├── main.js
├── src-tauri/
│   ├── Cargo.toml
│   ├── Cargo.lock
│   ├── build.rs
│   ├── tauri.conf.json
│   ├── src/
│   │   ├── main.rs
│   │   └── lib.rs
│   ├── icons/
│   │   ├── icon.png
│   │   ├── icon.icns
│   │   └── icon.ico
│   └── capabilities/
│       └── default.json
```

В данном случае проект на JavaScript находится в корневом уровне, а проект на Rust расположен внутри `src-tauri/`. Проект на Rust — это обычный [проект Cargo](https://doc.rust-lang.org/cargo/guide/project-layout.html) с некоторыми дополнительными файлами:

- `tauri.conf.json` — это основной файл конфигурации для Tauri, он содержит всё: от идентификатора приложения до URL сервера разработки. Этот файл также служит маркером для [CLI Tauri](/reference/cli/), чтобы найти проект на Rust. Чтобы узнать об этом больше, см. [Конфигурация Tauri](/ru/develop/configuration-files/#конфигурация-tauri).
- Каталог `capabilities/` — это папка по умолчанию, из которой Tauri читает [файлы возможностей](/ru/security/capabilities/) (кратко: здесь нужно разрешить команды, чтобы использовать их в своём коде JavaScript). Чтобы узнать об этом больше, см. раздел [Безопасность](/ru/security/).
- Каталог `icons/` — это каталог вывода по умолчанию команды [`tauri icon`](/reference/cli/#icon); обычно на него ссылаются в `tauri.conf.json > bundle > icon`, и он используется для значков приложения.
- `build.rs` содержит `tauri_build::build()`, которая используется для системы сборки tauri.
- `src/lib.rs` содержит код Rust и точку входа для мобильных устройств (функцию, помеченную `#[cfg_attr(mobile, tauri::mobile_entry_point)]`). Мы не пишем код непосредственно в `main.rs`, потому что при сборке для мобильных устройств ваше приложение компилируется в библиотеку и загружается через фреймворки платформы.
- `src/main.rs` — это главная точка входа для настольной версии, и мы запускаем `app_lib::run()` в `main`, чтобы использовать ту же точку входа, что и для мобильной версии. Поэтому, чтобы не усложнять, не изменяйте этот файл — изменяйте `lib.rs`. Обратите внимание, что `app_lib` соответствует `[lib.name]` в Cargo.toml.

Tauri работает аналогично статическому веб-хосту, и способ его сборки заключается в том, что вы сначала компилируете свой проект на JavaScript в статические файлы, а затем компилируете проект на Rust, который включит эти статические файлы в пакет. Поэтому настройка проекта на JavaScript, по сути, такая же, как при создании статического сайта. Чтобы узнать больше, см. раздел [Конфигурация фронтенда](/ru/start/frontend/).

Если вы хотите работать только с кодом Rust, просто удалите всё остальное и используйте папку `src-tauri/` в качестве основного проекта или члена вашего рабочего пространства (workspace) Rust.
