Tauri — это фреймворк для создания небольших и быстрых бинарных файлов для всех основных настольных и мобильных платформ. Разработчики могут интегрировать любой фронтенд-фреймворк, который компилируется в HTML, JavaScript и CSS, для построения пользовательского интерфейса, при необходимости используя такие языки, как Rust, Swift и Kotlin, для логики на стороне бэкенда.

Начните работу с [`create-tauri-app`](https://github.com/tauri-apps/create-tauri-app), используя одну из команд ниже. Обязательно следуйте [руководству по предварительным требованиям](/ru/start/prerequisites/), чтобы установить все зависимости, необходимые для Tauri. Для более подробного пошагового руководства см. [Создание проекта](/ru/start/create-project/#использование-create-tauri-app).

import Cta from '../../_fragments/cta.mdx';

<Cta />

После создания первого приложения ознакомьтесь с разделом [Структура проекта](/ru/start/project-structure/), чтобы понять, что делает каждый файл.

Или изучите конфигурации проектов и возможности из примеров ([tauri](https://github.com/tauri-apps/tauri/tree/dev/examples) | [plugins-workspace](https://github.com/tauri-apps/plugins-workspace/tree/v2/examples/api))

## Почему Tauri?

Tauri предлагает разработчикам 3 основных преимущества, на которых можно строить:

- Безопасная основа для создания приложений
- Меньший размер пакета благодаря использованию системного нативного WebView
- Гибкость: разработчики могут использовать любой фронтенд и привязки для множества языков

Узнайте больше о философии Tauri в [посте блога о Tauri 1.0](/ru/blog/tauri-1-0/).

### Безопасная основа

Поскольку Tauri построен на Rust, он может использовать такие преимущества Rust, как безопасность памяти, потокобезопасность и безопасность типов. Приложения, созданные на Tauri, автоматически получают эти преимущества даже без участия экспертов по Rust.

Кроме того, Tauri проходит аудит безопасности для всех основных и промежуточных версий. Это касается не только кода организации Tauri, но и вышестоящих зависимостей, на которые опирается Tauri. Конечно, это не устраняет все риски, но обеспечивает прочную основу, на которой разработчики могут строить свои приложения.

Ознакомьтесь с [политикой безопасности Tauri](https://github.com/tauri-apps/tauri/security/policy) и [отчётом об аудите Tauri 2.0](https://github.com/tauri-apps/tauri/blob/dev/audits/Radically_Open_Security-v2-report.pdf).

### Меньший размер приложения

Приложения Tauri используют WebView, уже доступный в системе каждого пользователя. Приложение Tauri содержит только код и ресурсы, специфичные для этого приложения, и ему не нужно включать движок браузера в каждое приложение. Это означает, что минимальное приложение Tauri может занимать менее 600 КБ.

Узнайте больше о создании оптимизированных приложений в разделе [Размер приложения](/ru/concept/size/).

### Гибкая архитектура

Так как Tauri использует веб-технологии, практически любой фронтенд-фреймворк совместим с Tauri. В [руководстве по настройке фронтенда](/ru/start/frontend/) содержатся типовые конфигурации для популярных фронтенд-фреймворков.

Разработчикам доступны привязки между JavaScript и Rust с помощью функции `invoke` в JavaScript, а для [плагинов Tauri](/ru/develop/plugins/) доступны привязки Swift и Kotlin.

[TAO](https://github.com/tauri-apps/tao) отвечает за создание окон Tauri, а [WRY](https://github.com/tauri-apps/wry) — за рендеринг WebView. Это библиотеки, поддерживаемые Tauri, которые можно использовать напрямую, если требуется более глубокая интеграция с системой за пределами возможностей Tauri.

Кроме того, Tauri поддерживает ряд плагинов, расширяющих возможности ядра Tauri. Эти плагины, наряду с созданными сообществом, вы можете найти в разделе [Плагины](/ru/plugin/).
