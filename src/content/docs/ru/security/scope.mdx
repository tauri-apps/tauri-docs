Область (scope) — это детальный способ определить (не)разрешённое поведение команды Tauri.

Области классифицируются как области `allow` или `deny`, где `deny` всегда
имеет приоритет над областью `allow`.

Тип области должен быть любого типа, сериализуемого [`serde`](https://docs.rs/serde/latest/serde/).
Эти типы в целом специфичны для плагинов. Для команд с областями, реализованных в приложении Tauri,
тип области нужно определить в приложении, а затем обеспечить его соблюдение в реализации команды.

Например, плагин [`Fs`](https://github.com/tauri-apps/plugins-workspace/tree/v2/plugins/fs) позволяет вам использовать области для разрешения или запрета определённых каталогов и файлов,
а плагин [`http`](https://github.com/tauri-apps/plugins-workspace/tree/v2/plugins/http) использует области для фильтрации URL-адресов, которых разрешено достигать.

Область передаётся в команду, а обработка или надлежащее соблюдение реализуется
самой командой.

:::caution

Разработчикам команд нужно обеспечивать отсутствие возможных обходов области.
Реализацию проверки области следует аудитировать для обеспечения корректности.

:::

## Примеры

Эти примеры взяты из разрешений плагина [`Fs`](https://github.com/tauri-apps/plugins-workspace/tree/v2/plugins/fs):

Тип области в этом плагине для всех команд — строка,
которая содержит путь, совместимый с [`glob`](https://docs.rs/glob/latest/glob/).

```toml title="plugins/fs/permissions/autogenerated/base-directories/applocaldata.toml"
[[permission]]
identifier = "scope-applocaldata-recursive"
description = '''
This scope recursive access to the complete `$APPLOCALDATA` folder,
including sub directories and files.
'''

[[permission.scope.allow]]
path = "$APPLOCALDATA/**"
```

```toml title="plugins/fs/permissions/deny-webview-data.toml"
[[permission]]
identifier = "deny-webview-data-linux"
description = '''
This denies read access to the
`$APPLOCALDATA` folder on linux as the webview data and
configuration values are stored here.
Allowing access can lead to sensitive information disclosure and
should be well considered.
'''
platforms = ["linux"]

[[permission.scope.deny]]
path = "$APPLOCALDATA/**"

[[permission]]
identifier = "deny-webview-data-windows"
description = '''
This denies read access to the
`$APPLOCALDATA/EBWebView` folder on windows as the webview data and
configuration values are stored here.
Allowing access can lead to sensitive information disclosure and
should be well considered.
'''
platforms = ["windows"]

[[permission.scope.deny]]
path = "$APPLOCALDATA/EBWebView/**"
```

Вышеуказанные области можно использовать для разрешения доступа к папке `APPLOCALDATA`, одновременно
предотвращая доступ к подпапке `EBWebView` на windows, которая содержит чувствительные данные webview.

Их можно объединить в набор, что сокращает дублирование конфигурации и делает её более
понятной для любого, кто изучает конфигурацию приложения.

Сначала области deny объединяются в `deny-default`:

```toml title="plugins/fs/permissions/deny-default.toml"
[[set]]
identifier = "deny-default"
description = '''
This denies access to dangerous Tauri relevant files and
folders by default.
'''
permissions = ["deny-webview-data-linux", "deny-webview-data-windows"]
```

Затем области deny и allow объединяются:

```toml
[[set]]
identifier = "scope-applocaldata-reasonable"
description = '''
This scope set allows access to the `APPLOCALDATA` folder and
subfolders except for linux,
while it denies access to dangerous Tauri relevant files and
folders by default on windows.
'''
permissions = ["scope-applocaldata-recursive", "deny-default"]
```

Эти области можно использовать либо для всех команд, расширяя глобальную область плагина,
либо только для выбранных команд при их использовании в сочетании с включённой командой внутри разрешения.

Разумный доступ только на чтение к файлам в `APPLOCALDATA` мог бы выглядеть так:

```toml
[[set]]
identifier = "read-files-applocaldata"
description = '''
This set allows file read access to the `APPLOCALDATA` folder and
subfolders except for linux,
while it denies access to dangerous Tauri relevant files and
folders by default on windows.'''
permissions = ["scope-applocaldata-reasonable", "allow-read-file"]
```

Эти примеры лишь иллюстрируют саму функциональность областей. Каждому разработчику плагина или приложения
нужно рассматривать разумные комбинации областей в зависимости от своих случаев использования.
