Runtime Authority — компонент ядра Tauri (Tauri Core), управляющий доступом во время выполнения.
Он хранит все разрешения (permissions), возможности (capabilities) и области видимости (scopes) во время выполнения, чтобы обеспечивать выполнение правил о том, какое окно имеет доступ к какой команде, и передаёт области видимости командам.

Когда команда Tauri вызывается из webview, Runtime Authority получает invoke-запрос, убеждается, что источнику фактически разрешено использовать запрошенную команду, проверяет, входит ли источник в capabilities и определены ли области видимости для команды; если да, они внедряются в invoke-запрос, который затем передаётся соответствующей команде Tauri.

Если источнику не разрешено вызывать команду, Runtime Authority отклонит запрос, и команда Tauri никогда не будет вызвана.
