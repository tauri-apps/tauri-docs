Наша экосистема организации Tauri размещена на GitHub и предоставляет несколько возможностей, делающих наши репозитории более устойчивыми к злоумышленникам, нацеленным на наш исходный код и релизы.

Чтобы снизить риски и соблюдать общепринятые лучшие практики, мы внедрили следующие методы.

### Конвейеры сборки

Процесс выпуска наших артефактов исходного кода сильно автоматизирован в конвейерах сборки GitHub с использованием GitHub Actions, но требует запуска и проверки реальными людьми.

### Подписанные коммиты

Наши основные репозитории требуют подписанных коммитов для снижения риска выдавания себя за другое лицо и для возможности идентификации коммитов после обнаружения возможной компрометации.

### Ревью кода

Все пул-реквесты (PR), вливаемые в наши репозитории, требуют одобрения как минимум одного мейнтейнера проекта, которым в большинстве случаев является рабочая группа.
Код обычно проверяется в PR, а стандартные рабочие процессы и проверки безопасности запускаются для обеспечения соответствия кода общим стандартам.

### Процесс релиза

Наша рабочая группа проверяет изменения кода, помечает PR областью (scope), и следит за тем, чтобы всё оставалось актуальным.
Мы стремимся внутренне аудировать все PR, значимые для безопасности, перед публикацией минорных и мажорных релизов.

А когда приходит время публиковать новую версию, один из мейнтейнеров помечает новый релиз в dev, который:

- Проверяет ядро
- Запускает тесты
- Аудирует безопасность крейтов и npm пакетов
- Генерирует changelog
- Создаёт артефакты
- Создаёт черновой релиз

Затем мейнтейнер проверяет заметки о релизе, при необходимости редактирует их, и новый релиз выпускается.
