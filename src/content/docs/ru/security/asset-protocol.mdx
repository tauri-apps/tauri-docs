Tauri может раздавать файлы с диска в WebView через пользовательский протокол **asset** (например, когда вы используете [`convertFileSrc`](/reference/javascript/api/namespacecore/#convertfilesrc) во фронтенде). Доступность пути определяется настройкой **`app.security.assetProtocol`** в `tauri.conf.json`.

Вы должны установить **`enable`** в `true` и задать **`scope`**, перечисляющий пути файловой системы, которые могут быть открыты. Пути, разрешаемые во время выполнения, должны соответствовать этой области видимости, иначе WebView откажется загружать файл (часто с ошибкой вида «asset protocol not configured to allow the path»).

Политика безопасности контента для источников `asset:` описана на странице [Политика безопасности контента (CSP)](/ru/security/csp/). Эта страница посвящена **области видимости** и её взаимодействию с glob-шаблонами и скрытыми сегментами пути.

## Как определяется `scope`

`assetProtocol.scope` использует тот же тип **`FsScope`**, что и связанные с файловой системой настройки: либо **JSON-массив** разрешённых glob-шаблонов, либо **JSON-объект** с `allow`, необязательным `deny` и необязательным `requireLiteralLeadingDot`. О том, как «области видимости» вписываются в модель безопасности Tauri в целом, см. [Области видимости команд](/ru/security/scope/).

Шаблоны могут начинаться с **переменной базового каталога** (например, `$HOME`, `$CACHE`, `$APPCACHE`, `$APPDATA`, `$RESOURCE`). Полный набор переменных, на которые может полагаться ваше приложение, см. в [API путей / базовых каталогов](/reference/javascript/api/namespacepath/#basedirectory).

Пути, разрешаемые при загрузке ресурсов, обычно являются **абсолютными** (в Linux часто находятся в `/home/...`). Шаблон вида `["*/**"]` обычно **не** соответствует таким путям, поскольку не согласуется с ведущим `/` или переменной базового каталога. Предпочитайте шаблоны вида `$HOME/**/*`, `/home/username/**/*` или другую форму, отражающую реально разрешённый путь.

### Форма массива (только разрешённые пути)

Используйте список, когда вам нужен только фиксированный список разрешений и поведения glob по умолчанию достаточно:

```json title="src-tauri/tauri.conf.json"
{
  "app": {
    "security": {
      "assetProtocol": {
        "enable": true,
        "scope": ["$APPCACHE/**/*", "$RESOURCE/**/*"]
      }
    }
  }
}
```

В форме массива вы **не можете** задать `requireLiteralLeadingDot`; для этого используйте форму объекта ниже.

### Форма объекта (`allow`, `deny`, `requireLiteralLeadingDot`)

Используйте объект, когда вам нужны правила **deny** или изменение сопоставления **точек в начале пути**:

```json title="src-tauri/tauri.conf.json"
{
  "app": {
    "security": {
      "assetProtocol": {
        "enable": true,
        "scope": {
          "allow": ["$APPCACHE/**/*"],
          "deny": ["$APPCACHE/**/secrets/**"]
        }
      }
    }
  }
}
```

`deny` имеет приоритет над `allow`, когда совпадают оба.

## Unix: сегменты пути, начинающиеся с `.`

В Unix `requireLiteralLeadingDot` по умолчанию равен **`true`**. В этом случае символы подстановки, такие как `*`, `?`, `**` и `[...]`, **не сопоставляются с компонентом пути, который начинается с** `.` (скрытые файлы и каталоги, например `.cache` или `.ssh`).

Так, шаблон вида `$HOME/**` может разрешить `/home/user/Documents/file.png`, но **не** `/home/user/.cache/myapp/preview.png`, поскольку `.cache` — это компонент, начинающийся с точки. Шаблон, называющий сегмент явно (например, `$HOME/.cache/myapp/**`), **сопоставляется**.

Чтобы разрешить компоненты, начинающиеся с точки, в широком glob-шаблоне, можно установить **`requireLiteralLeadingDot`** в **`false`** в **объекте** `scope` (это расширяет то, что может загружать WebView; оценивайте внимательно):

```json title="src-tauri/tauri.conf.json"
{
  "app": {
    "security": {
      "assetProtocol": {
        "enable": true,
        "scope": {
          "requireLiteralLeadingDot": false,
          "allow": ["$HOME/**/*"]
        }
      }
    }
  }
}
```

:::tip[Всё ещё блокируются пути в стиле Linux?]

Участники сообщества часто сталкиваются с этим, когда путь проходит через **каталог с точкой** (например, `~/.cache/...`), а шаблон разрешения использует только `**` внутри `$HOME`. См. обсуждение в [tauri#13788](https://github.com/tauri-apps/tauri/issues/13788) с конкретными примерами и решениями.

:::

## Предпочитайте `**/*` вместо голого `**` для «всех файлов здесь»

Для glob-шаблонов, которые должны сопоставляться с **файлами** внутри дерева, предпочитайте `**/*` (и варианты вроде `$DIR/**/*`), а не голый `**`, как и в других примерах путей Tauri. Голый `**` легко использовать неправильно, когда вы имеете в виду «всё в этом каталоге рекурсивно».

## Высокоразрешённая конфигурация (использовать с крайней осторожностью)

Если вам намеренно нужен максимально широкий доступ **и** сегменты, начинающиеся с точки, форма, предлагаемая мейнтейнерами, выглядит так. **Это не рекомендация по умолчанию**; она увеличивает доступность скрытых и чувствительных файлов.

```json title="src-tauri/tauri.conf.json"
{
  "app": {
    "security": {
      "assetProtocol": {
        "enable": true,
        "scope": {
          "requireLiteralLeadingDot": false,
          "allow": ["**/*"]
        }
      }
    }
  }
}
```

:::caution

Предпочитайте **узкие** каталоги (`$APPCACHE`, `$RESOURCE`, отдельную вложенную папку приложения внутри `$HOME` и т. д.) вместо широких `$HOME/**/*` или `**/*`, если у вас нет веских причин и понимания компромиссов безопасности.

:::

## Статическая конфигурация против динамически выбираемых путей

Записи в **`tauri.conf.json`** описывают **статические** шаблоны разрешения/запрета. Они не заменяют рабочие процессы времени выполнения, где пользователь выбирает произвольные папки или файлы (например, с помощью плагина **dialog**): такие пути, возможно, потребуется **сохранять** между перезапусками с помощью плагина [**persisted-scope**](/ru/plugin/persisted-scope/).

Чтобы сохранять область видимости, связанную с **asset** / протоколом, с помощью этого плагина, включите его Cargo-функцию **`protocol-asset`** в `src-tauri/Cargo.toml`, например:

```toml
tauri-plugin-persisted-scope = { version = "2", features = ["protocol-asset"] }
```

Зарегистрируйте **`tauri_plugin_fs`** до **`tauri_plugin_persisted_scope`**, как описано в руководстве по плагинам.

## Устранение неполадок

| Симптом                                                             | Что проверить                                                                                                                                                                                                                                             |
| ------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| «asset protocol not configured to allow the path»                   | Путь должен соответствовать шаблону **`allow`**; **`deny`** переопределяет **`allow`**. Используйте **абсолютные** шаблоны или переменные вида **`$VAR`/`$HOME`**, соответствующие тому, как путь разрешается на диске. |
| Работает для обычных папок, но не внутри **`.cache`** / **`.config`** | В Unix поведение **`requireLiteralLeadingDot`** по умолчанию: используйте литеральный `.segment` в шаблоне или установите **`requireLiteralLeadingDot`: `false`** в объекте `scope` (см. [tauri#13788](https://github.com/tauri-apps/tauri/issues/13788)). |
| Пользователь выбрал папку во время выполнения; всё ещё заблокировано после перезапуска        | Возможно, вам понадобится [**persisted-scope**](/ru/plugin/persisted-scope/) с функцией **`protocol-asset`**, а не только записи в `tauri.conf.json`.                                                                                                     |
| Широкий `**` ведёт себя неверно                                              | Попробуйте `**/*` для glob-шаблонов, ориентированных на файлы; см. [Встраивание дополнительных файлов](/ru/develop/resources/) с аналогичными рекомендациями о `**` против `**/*` для ресурсов бандла.                                                       |
| Область вида `["*/**"]` никогда не совпадает в Linux                        | Разрешаемые пути **абсолютные**; используйте переменные **`$...`**, ведущий **`/`** или другой шаблон, соответствующий реальному пути (см. выше).                                                                                                           |

Авторитетные типы Rust для `assetProtocol` и `FsScope` находятся в [`config.rs`](https://github.com/tauri-apps/tauri/blob/dev/crates/tauri-utils/src/config.rs) Tauri (`AssetProtocolConfig`, `FsScope`). Сгенерированный [справочник по конфигурации](/reference/config/) может отображать вложенные поля `FsScope` компактно или трудночитаемо; если что-то выглядит неясным, сверьтесь с этой страницей и разделом `requireLiteralLeadingDot` [плагина файловой системы](/ru/plugin/file-system/) (конфигурация плагина использует то же имя опции для собственных областей видимости). Если в справочнике эти поля по-прежнему описаны нечётко, рассмотрите возможность открыть issue в репозитории **tauri-docs**, чтобы генератор конфигурации был улучшен.
