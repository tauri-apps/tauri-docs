[CrabNebula](https://crabnebula.dev/) предоставляет бесплатное приложение [DevTools](https://crabnebula.dev/devtools/) для Tauri в рамках партнёрства с проектом Tauri. Это приложение позволяет инструментировать ваше Tauri-приложение, захватывая его встроенные ресурсы, файл конфигурации Tauri, логи и спаны, предоставляя веб-интерфейс для наглядной визуализации данных в реальном времени.

С помощью CrabNebula DevTools вы можете просматривать события логов вашего приложения (включая логи из зависимостей), отслеживать производительность вызовов ваших команд и общее использование API Tauri, с помощью специального интерфейса для событий и команд Tauri, включая полезную нагрузку, ответы, внутренние логи и спаны выполнения.

Чтобы включить CrabNebula DevTools, установите крейт devtools:

```sh frame=none
cargo add tauri-plugin-devtools@2.0.0
```

И инициализируйте плагин как можно раньше в вашей функции `main`:

```rust
fn main() {
    // This should be called as early in the execution of the app as possible
    #[cfg(debug_assertions)] // only enable instrumentation in development builds
    let devtools = tauri_plugin_devtools::init();

    let mut builder = tauri::Builder::default();

    #[cfg(debug_assertions)]
    {
        builder = builder.plugin(devtools);
    }

    builder
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

Затем запустите ваше приложение как обычно. Если всё настроено правильно, devtools выведет следующее сообщение:

<Image src={devToolsPrint} alt="DevTools message on terminal" />

:::note
В данном случае мы инициализируем плагин devtools только для отладочных приложений, что рекомендуется.
:::

Дополнительную информацию см. в документации [CrabNebula DevTools](https://docs.crabnebula.dev/devtools/get-started/).
