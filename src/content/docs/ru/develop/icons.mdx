Tauri поставляется с набором иконок по умолчанию на основе своего логотипа. Это НЕ то, что вам нужно, когда вы выпускаете своё приложение. Чтобы исправить эту распространённую ситуацию, Tauri предоставляет команду `icon`, которая принимает входной файл (по умолчанию `"./app-icon.png"`) и создаёт все иконки, необходимые для различных платформ.

:::note[Примечание о типах файлов]

- `icon.icns` = macOS
- `icon.ico` = Windows
- `*.png` = Linux
- `Square*Logo.png` и `StoreLogo.png` = В настоящее время не используются, но предназначены для целевых платформ AppX/MS Store.

Некоторые типы иконок могут использоваться на платформах, отличных от перечисленных выше (особенно `png`). Поэтому мы рекомендуем включать все иконки, даже если вы планируете собирать только для подмножества платформ.

:::

## Использование команды

<CommandTabs
  npm="npm run tauri icon"
  yarn="yarn tauri icon"
  pnpm="pnpm tauri icon"
  cargo="cargo tauri icon"
  deno="deno task tauri icon"
/>

```console
> pnpm tauri icon --help

Generate various icons for all major platforms

Usage: pnpm run tauri icon [OPTIONS] [INPUT]

Arguments:
  [INPUT]  Path to the source icon (squared PNG or SVG file with transparency) [default: ./app-icon.png]

Options:
  -o, --output <OUTPUT>        Output directory. Default: 'icons' directory next to the tauri.conf.json file
  -v, --verbose...             Enables verbose logging
  -p, --png <PNG>              Custom PNG icon sizes to generate. When set, the default icons are not generated
      --ios-color <IOS_COLOR>  The background color of the iOS icon - string as defined in the W3C's CSS Color Module Level 4 <https://www.w3.org/TR/css-color-4/> [default: #fff]
  -h, --help                   Print help
  -V, --version                Print version
```

Иконки для **настольных** платформ по умолчанию будут помещены в вашу папку `src-tauri/icons`, откуда они автоматически включаются в создаваемое приложение. Если вы хотите брать иконки из другого места, вы можете изменить эту часть файла `tauri.conf.json`:

```json
{
  "bundle": {
    "icon": [
      "icons/32x32.png",
      "icons/128x128.png",
      "icons/128x128@2x.png",
      "icons/icon.icns",
      "icons/icon.ico"
    ]
  }
}
```

Иконки для **мобильных** платформ будут помещены непосредственно в проекты Xcode и Android Studio!

## Создание иконок вручную

Если вы предпочитаете создавать эти иконки самостоятельно, например если вы хотите иметь более простое оформление для маленьких размеров или не хотите зависеть от внутреннего изменения размера изображений в CLI, вы должны убедиться, что ваши иконки соответствуют некоторым требованиям:

- `icon.icns`: Требуемые размеры и имена слоёв для файла [`icns`] описаны [в репозитории Tauri]
- `icon.ico`: Файл [`ico`] должен включать слои на 16, 24, 32, 48, 64 и 256 пикселей. Для оптимального отображения изображения ICO _во время разработки_ слой 32px должен быть первым слоем.
- `png`: Требования к иконкам png: ширина == высота, RGBA (RGB + прозрачность) и 32 бита на пиксель (8 бит на канал). Обычно ожидаемые размеры на настольных платформах — 32, 128, 256 и 512 пикселей. Мы рекомендуем как минимум соответствовать выводу `tauri icon`: `32x32.png`, `128x128.png`, `128x128@2x.png` и `icon.png`.

### Android

В Android вам понадобятся png-иконки с теми же требованиями, но разных размеров. Их также нужно будет разместить непосредственно в проекте Android Studio:

- `src-tauri/gen/android/app/src/main/res/`
  - `mipmap-hdpi/`
    - `ic_launcher.png` и `ic_launcher_round.png`: 49x49px
    - `ic_launcher_foreground.png`: 162x162px
  - `mipmap-mdpi/`
    - `ic_launcher.png` и `ic_launcher_round.png`: 48x48px
    - `ic_launcher_foreground.png`: 108x108px
  - `mipmap-xhdpi/`
    - `ic_launcher.png` и `ic_launcher_round.png`: 96x96px
    - `ic_launcher_foreground.png`: 216x216px
  - `mipmap-xxhdpi/`
    - `ic_launcher.png` и `ic_launcher_round.png`: 144x144px
    - `ic_launcher_foreground.png`: 324x324px
  - `mipmap-xxxhdpi/`
    - `ic_launcher.png` и `ic_launcher_round.png`: 192x192px
    - `ic_launcher_foreground.png`: 432x432px

Если `tauri icon` использовать нельзя, мы рекомендуем обратить внимание на [Studio ресурсов изображений] Android Studio.

### iOS

В iOS вам понадобятся png-иконки с теми же требованиями, но **без прозрачности** и разных размеров. Их также нужно будет разместить непосредственно в проекте Xcode в `src-tauri/gen/apple/Assets.xcassets/AppIcon.appiconset/`. Ожидаются следующие иконки:

- 20px в 1x, 2x, 3x, с дополнительной иконкой
- 29px в 1x, 2x, 3x, с дополнительной иконкой
- 40px в 1x, 2x, 3x, с дополнительной иконкой
- 60px в 2x, 3x
- 76px в 1x, 2x
- 83.5px в 2x
- 512px в 2x, сохранённая как `AppIcon-512@2x.png`

Имена файлов имеют формат `AppIcon-{size}x{size}@{scaling}{extra}.png`. Для иконок 20px это означает, что вам нужны иконки размеров 20x20, 40x40 и 60x60 с именами `AppIcon-20x20@1x.png`, `AppIcon-20x20@2x.png`, `AppIcon-20x20@3x.png`, а `2x` дополнительно сохраняется как `AppIcon-20x20@2x-1.png` («дополнительная иконка»).
