[WebDriver] — это стандартизированный интерфейс для взаимодействия с веб-документами, предназначенный в первую очередь для автоматизированного тестирования. Рекомендуемый
способ использования его с Tauri — [WebdriverIO] и [`@wdio/tauri-service`], которые работают на **Windows, Linux
и macOS**. Поддерживаясь в рамках проекта WebdriverIO, он предоставляет доступ к API Tauri через `browser.tauri.execute()`,
макетирование команд (IPC), захват логов фронтенда и бэкенда, а также multiremote.

По умолчанию сервис запускает **встроенный сервер WebDriver** внутри вашего приложения, поэтому внешний драйвер не нужен ни на какой
платформе — и именно так поддерживается macOS. Он также может использовать собственный WebDriver платформы через [`tauri-driver`]
на Windows и Linux или кроссплатформенный форк `tauri-driver` от [CrabNebula] на всех платформах (для macOS требуется
платный ключ API). Какой бы путь вы ни выбрали, сервис обнаруживает бинарный файл вашего приложения, а на пути
`tauri-driver` синхронизирует Edge WebDriver на Windows за вас.

Самый быстрый способ создать проект — стартовый шаблон WebdriverIO:

```shell
npm create wdio@latest ./
```

Выберите **Desktop Testing** и выберите **Tauri** в приглашении выбора фреймворка. Минимальная конфигурация выглядит так:

```typescript
export const config: WebdriverIO.Config = {
  services: [
    [
      'tauri',
      {
        appBinaryPath: './src-tauri/target/release/my-tauri-app',
        driverProvider: 'embedded',
      },
    ],
  ],
};
```

Эта настройка использует два небольших плагина Tauri, оба необязательны в зависимости от ваших требований:

- **`tauri-plugin-wdio-webdriver`** запускает встроенный сервер WebDriver. Он обязателен для провайдера `embedded` (по
  умолчанию) — сервис управляет вашим приложением через него, без внешнего драйвера, и именно так поддерживается macOS. Вы можете
  пропустить его, если хотите использовать провайдер `external` или `crabnebula`.
- **`tauri-plugin-wdio`** включает доступ к бэкенду, включая: `browser.tauri.execute()`, макетирование команд (IPC) и захват
  логов.

См. [Настройка плагина] для полных шагов и [руководство по настройке CrabNebula], если вы используете этот провайдер.

Для быстрых тестов только рендерера также существует **режим браузера**, который запускает ваш фронтенд Tauri в обычном Chrome против
Vite dev-сервера — без бинарного файла Tauri, драйвера или плагина. Он перехватывает вызовы `invoke()`, чтобы вы могли макетировать команды
и проверять их аргументы с помощью того же API WDIO. См. [руководство по режиму браузера].

## Использование `tauri-driver` напрямую

Если вы не используете Node.js, предпочитаете [Selenium] или интегрируете WebDriver в собственный тестовый каркас, вы можете использовать
[`tauri-driver`] напрямую вместо сервиса. При прямом использовании на десктопе поддерживаются только Windows и Linux,
поскольку для macOS нет доступного инструмента драйвера WKWebView (для macOS используйте встроенный сервер WebDriver сервиса).
