Эта страница описывает использование [`tauri-driver`] напрямую, без [`@wdio/tauri-service`]. Обратитесь к ней, если вы не
используете Node.js, предпочитаете [Selenium] или интегрируете WebDriver в собственный тестовый каркас. Для большинства проектов сервис —
более простой путь: он автоматизирует всё нижеперечисленное и дополнительно поддерживает macOS. См. [обзор WebDriver], чтобы
начать работу с ним.

При прямом использовании `tauri-driver` на десктопе поддерживаются только Windows и Linux, поскольку для macOS нет доступного
инструмента драйвера WKWebView. iOS и Android работают через Appium 2, но этот процесс в настоящее время не отлажен.

<a id="system-dependencies"></a>
## Системные зависимости

Установите последнюю версию [`tauri-driver`] или обновите существующую установку, выполнив:

```shell
cargo install tauri-driver --locked
```

Поскольку в настоящее время мы используем собственный сервер [WebDriver] платформы, существуют некоторые требования для запуска
[`tauri-driver`] на поддерживаемых платформах.

### Linux

На платформах Linux мы используем `WebKitWebDriver`. Проверьте, существует ли этот бинарный файл, выполнив команду `which WebKitWebDriver`, так как
некоторые дистрибутивы включают его в обычный пакет WebKit. На других платформах для него может быть отдельный пакет, например
`webkit2gtk-driver` в дистрибутивах на основе Debian.

### Windows

Обязательно загрузите версию [Microsoft Edge Driver], соответствующую версии вашего Windows Edge, под которую строится и на которой
тестируется приложение. На обновлённых установках Windows это почти всегда должна быть последняя стабильная версия. Если
две версии не совпадают, ваш набор тестов WebDriver может зависнуть при попытке подключения.

Вы можете использовать [msedgedriver-tool](https://github.com/chippers/msedgedriver-tool) для загрузки подходящего Microsoft Edge Driver:

```powershell
cargo install --git https://github.com/chippers/msedgedriver-tool
& "$HOME/.cargo/bin/msedgedriver-tool.exe"
```

Загрузка содержит бинарный файл с именем `msedgedriver.exe`. [`tauri-driver`] ищет этот бинарный файл в `$PATH`, поэтому убедитесь,
что он доступен в пути, либо используйте опцию `--native-driver` у [`tauri-driver`]. Возможно, вы захотите загружать его автоматически как часть процесса настройки CI, чтобы гарантировать синхронизацию версий Edge и Edge Driver
на Windows-машинах CI. Руководство о том, как это сделать, может быть добавлено позднее.
