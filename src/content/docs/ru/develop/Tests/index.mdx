Tauri поддерживает как модульное, так и интеграционное тестирование с использованием макетной среды выполнения. В макетной среде выполнения собственные
библиотеки webview не выполняются. [Узнайте больше о макетной среде выполнения здесь].

Tauri также предоставляет поддержку сквозного тестирования с использованием протокола WebDriver. [Тестирование Tauri с WebdriverIO]
поддерживает Windows, Linux и macOS; протокол WebDriver также можно использовать напрямую на Windows и Linux, поскольку macOS
не предоставляет десктопного клиента WebDriver. [Узнайте больше о поддержке WebDriver здесь].

Мы предлагаем [tauri-action] для помощи с запуском GitHub Actions, но с Tauri можно использовать любой тип CI/CD-раннера, если на каждой
платформе установлены необходимые библиотеки для компиляции.
