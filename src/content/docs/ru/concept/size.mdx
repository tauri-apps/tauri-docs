Хотя Tauri по умолчанию предоставляет очень маленькие бинарные файлы, не помешает немного раздвинуть границы, поэтому вот несколько советов и приёмов для достижения оптимальных результатов.

## Конфигурация Cargo

Одно из самых простых улучшений размера, не зависящих от фронтенда, которое вы можете сделать в своём проекте, — добавить профиль Cargo.

В зависимости от того, используете ли вы стабильный или nightly инструментарий Rust, доступные вам параметры немного отличаются. Рекомендуется придерживаться стабильного инструментария, если вы не продвинутый пользователь.

<Tabs>
<TabItem label="Stable">

```toml
# src-tauri/Cargo.toml
[profile.dev]
incremental = true # Компилируйте ваш бинарный файл меньшими шагами.

[profile.release]
codegen-units = 1 # Позволяет LLVM выполнять лучшую оптимизацию.
lto = true # Включает оптимизации на этапе связывания.
opt-level = "s" # Приоритезирует небольшой размер бинарного файла. Используйте `3`, если предпочитаете скорость.
panic = "abort" # Более высокая производительность за счёт отключения обработчиков паник.
strip = true # Гарантирует удаление отладочных символов.
```

</TabItem>

<TabItem label="Nightly">

```toml
# src-tauri/Cargo.toml
[profile.dev]
incremental = true # Компилируйте ваш бинарный файл меньшими шагами.
rustflags = ["-Zthreads=8"] # Лучшая производительность компиляции.

[profile.release]
codegen-units = 1 # Позволяет LLVM выполнять лучшую оптимизацию.
lto = true # Включает оптимизации на этапе связывания.
opt-level = "s" # Приоритезирует небольшой размер бинарного файла. Используйте `3`, если предпочитаете скорость.
panic = "abort" # Более высокая производительность за счёт отключения обработчиков паник.
strip = true # Гарантирует удаление отладочных символов.
trim-paths = "all" # Удаляет потенциально привилегированную информацию из ваших бинарных файлов.
rustflags = ["-Cdebuginfo=0", "-Zthreads=8"] # Лучшая производительность компиляции.
```

</TabItem>

### Ссылки

:::note
Это не полный справочник по всем доступным параметрам, а лишь те, на которые мы хотим обратить особое внимание.
:::

- [incremental:](https://doc.rust-lang.org/cargo/reference/profiles.html#incremental) Компилируйте ваш бинарный файл меньшими шагами.
- [codegen-units:](https://doc.rust-lang.org/cargo/reference/profiles.html#codegen-units) Ускоряет время компиляции за счёт оптимизаций времени компиляции.
- [lto:](https://doc.rust-lang.org/cargo/reference/profiles.html#lto) Включает оптимизации на этапе связывания.
- [opt-level:](https://doc.rust-lang.org/cargo/reference/profiles.html#opt-level) Определяет фокус компилятора. Используйте `3` для оптимизации производительности, `z` для оптимизации под размер и `s` для чего-то среднего.
- [panic:](https://doc.rust-lang.org/cargo/reference/profiles.html#panic) Уменьшите размер, удалив раскрутку паник.
- [strip:](https://doc.rust-lang.org/cargo/reference/profiles.html#strip) Удалите из бинарного файла либо символы, либо отладочную информацию.
- [rpath:](https://doc.rust-lang.org/cargo/reference/profiles.html#rpath) Помогает находить динамические библиотеки, которые требует бинарный файл, жёстко зашивая информацию в него.
- [trim-paths:](https://rust-lang.github.io/rfcs/3127-trim-paths.html) Удаляет потенциально привилегированную информацию из бинарных файлов.
- [rustflags:](https://doc.rust-lang.org/nightly/cargo/reference/unstable.html#profile-rustflags-option) Задаёт флаги компилятора Rust для каждого профиля отдельно.
  - `-Cdebuginfo=0`: Включать ли символы отладочной информации в сборку.
  - `-Zthreads=8`: Увеличивает количество потоков, используемых во время компиляции.

## Удаление неиспользуемых команд

В пул-реквесте [`feat: add a new option to remove unused commands`](https://github.com/tauri-apps/tauri/pull/12890) мы добавили новый параметр в файл конфигурации tauri

```json title=tauri.conf.json
{
  "build": {
    "removeUnusedCommands": true
  }
}
```

для удаления команд, которые никогда не разрешены в ваших файлах возможностей (ACL), чтобы вам не приходилось платить за то, что вы не используете

:::tip
Чтобы получить максимум от этого, включайте в ACL только те команды, которые вы используете, вместо использования `defaults`
:::

:::note
Эта функция требует `tauri@2.4`, `tauri-build@2.1`, `tauri-plugin@2.1` и `tauri-cli@2.4`
:::

:::note
Это не будет учитывать динамически добавляемые ACL во время выполнения, поэтому обязательно проверяйте это при использовании
:::

<details>
<summary>Как это работает под капотом?</summary>

`tauri-cli` будет взаимодействовать с `tauri-build` и сборочным скриптом `tauri`, `tauri-plugin` через переменную окружения
и позволит им сгенерировать список разрешённых команд из ACL,
затем это будет использовано макросом `generate_handler` для удаления неиспользуемых команд на основе этого

Внутренняя деталь: эта переменная окружения в настоящее время называется `REMOVE_UNUSED_COMMANDS`,
и она устанавливается в каталог проекта, обычно в каталог `src-tauri`, это используется сборочными скриптами для поиска файлов возможностей,
и хотя это не поощряется, вы всё ещё можете установить эту переменную окружения самостоятельно, если не можете или не хотите использовать `tauri-cli` для этого
(**обратите внимание, что поскольку это деталь реализации, мы не гарантируем её стабильность**)

</details>
