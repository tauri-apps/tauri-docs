_**Это паттерн по умолчанию.**_

Это самый простой и самый понятный способ использования Tauri, поскольку он старается быть как можно более совместимым с существующими проектами фронтенда. Короче говоря, он старается не требовать ничего
дополнительного сверх того, что существующий веб-фронтенд может использовать в браузере.
Не **_всё_**, что работает в существующих браузерных приложениях, будет работать из коробки.

Если вы в целом не знакомы с разработкой ПО по методологии Brownfield, [статья о Brownfield в Википедии]
даёт хорошую сводку. Для Tauri существующее программное обеспечение — это текущая поддержка и поведение браузера, а не
унаследованные системы.

<a id="configuration"></a>

## Конфигурация

Поскольку паттерн Brownfield является паттерном по умолчанию, для него не требуется устанавливать параметр конфигурации. Чтобы явно задать
его, вы можете использовать объект `app > security > pattern` в файле конфигурации `tauri.conf.json`.

```json
{
  "app": {
    "security": {
      "pattern": {
        "use": "brownfield"
      }
    }
  }
}
```

_**Для паттерна brownfield не существует дополнительных параметров конфигурации.**_

[статья о brownfield в википедии]: https://en.wikipedia.org/wiki/Brownfield_(software_development)
