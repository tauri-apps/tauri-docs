Мы, мейнтейнеры, очень рады, что вы заинтересованы внести вклад в Tauri. Мы приветствуем участников любого уровня навыков и рады предоставить руководство по PR.
При любых сомнениях вы можете связаться с нами на [нашем Discord-сервере](https://discord.gg/SpmNs4S).

### Репозитории проекта

Основные репозитории Tauri, в которые вы можете внести вклад:

- [Tauri Core](https://github.com/tauri-apps/tauri/) — репозиторий, содержащий среду выполнения Tauri, инструменты сборки, макросы и утилиты.
- [Plugins Workspace](https://github.com/tauri-apps/plugins-workspace) — репозиторий со всеми официальными плагинами Tauri
- [Tauri Docs](https://github.com/tauri-apps/tauri-docs) — репозиторий, содержащий этот сайт

Каждый из этих репозиториев Tauri содержит файл `.github/CONTRIBUTING.md`. В нём вы найдёте инструкции о том, как настроить локальную среду разработки и отправить пул-реквест.

### Перевод

Документация Tauri доступна на нескольких языках: английском, французском, испанском, китайском (упрощённом), японском, корейском и русском. Вклад в переводы приветствуется.

При переводе или ревью документации рассмотрите использование следующих инструментов:

- **zhlint** — инструмент линтинга для китайского текста, проверяющий пунктуацию, пробелы и другие распространённые проблемы. Рекомендуется участникам, работающим над локалью `zh-cn`. Доступен на [zhlint.jinjiang.dev](https://zhlint.jinjiang.dev/).
- **Chinese Copywriting Guidelines** — руководство по стилю для написания согласованного и корректного китайского текста. Доступно на [github.com/sparanoid/chinese-copywriting-guidelines](https://github.com/sparanoid/chinese-copywriting-guidelines).
- **Starlight i18n VS Code extension** — полезное расширение для управления i18n-контентом на сайтах документации на основе Starlight. Доступно на [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=hideoo.starlight-i18n).
