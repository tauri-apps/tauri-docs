В этом руководстве представлена информация о подписи кода для пакетов Linux. Хотя подпись артефактов не требуется для развёртывания вашего приложения на Linux, её можно использовать для повышения доверия к развёрнутому приложению. Подпись бинарных файлов позволяет конечному пользователю убедиться, что они подлинные и не были изменены другой ненадёжной стороной.

## Подпись для AppImages

AppImage можно подписать с помощью gpg или gpg2.

### Предварительные требования

Должен быть подготовлен ключ для подписи. Новый ключ можно сгенерировать с помощью:

```shell
gpg2 --full-gen-key
```

Дополнительную информацию см. в документации gpg или gpg2. Следует уделить дополнительное внимание резервному копированию ваших закрытых и открытых ключей в безопасное место.

<a id="signing"></a>
### Подпись

Вы можете встроить подпись в AppImage, задав следующие переменные окружения:

- **SIGN**: задайте `1`, чтобы подписать AppImage.
- **SIGN_KEY**: необязательная переменная для использования конкретного GPG Key ID при подписи.
- **APPIMAGETOOL_SIGN_PASSPHRASE**: пароль ключа подписи. Если не задан, gpg показывает диалог для ввода. Вы должны задать это при сборке на платформах CI/CD.
- **APPIMAGETOOL_FORCE_SIGN**: по умолчанию AppImage генерируется даже в случае сбоя подписи. Чтобы завершать работу при ошибках, вы можете задать этой переменной значение `1`.

Вы можете отобразить подпись, встроенную в AppImage, выполнив следующую команду:

```shell
./src-tauri/target/release/bundle/appimage/$APPNAME_$VERSION_amd64.AppImage --appimage-signature
```

Обратите внимание, что вам нужно заменить значения $APPNAME и $VERSION на правильные в соответствии с вашей конфигурацией.

:::caution

**Подпись не проверяется**

AppImage не проверяет подпись, поэтому вы не можете полагаться на неё, чтобы проверить, был ли файл изменён. Пользователь должен вручную проверить подпись с помощью инструмента AppImage validate. Это требует, чтобы вы опубликовали свой идентификатор ключа в аутентифицированном канале (например, на вашем сайте, обслуживаемом через TLS), чтобы конечный пользователь мог просмотреть и проверить его.

Дополнительную информацию см. в [официальной документации AppImage][the official appimage documentation].

:::

[the official appimage documentation]: https://docs.appimage.org/packaging-guide/optional/signatures.html

### Проверка подписи

Инструмент AppImage validate можно загрузить [отсюда](https://github.com/AppImageCommunity/AppImageUpdate/releases/tag/continuous). Выберите один из файлов `validate-$PLATFORM.AppImage`.

Выполните следующую команду для проверки подписи:

```shell
chmod +x validate-$PLATFORM.AppImage
./validate-$PLATFORM.AppImage $TAURI_OUTPUT.AppImage
```

Если подпись действительна, вывод будет следующим:

```
Validation result: validation successful
Signatures found with key fingerprints: $KEY_ID
====================
Validator report:
Signature checked for key with fingerprint $KEY_ID:
Validation successful
```
