Tauri предоставляет инструменты, необходимые для распространения вашего приложения — либо в магазинах приложений платформ, либо в виде установщиков для конкретных платформ.

## Сборка

Tauri собирает ваше приложение напрямую из своего CLI с помощью команд `build`, `android build` и `ios build`.

<CommandTabs
  npm="npm run tauri build"
  yarn="yarn tauri build"
  pnpm="pnpm tauri build"
  deno="deno task tauri build"
  bun="bun tauri build"
  cargo="cargo tauri build"
/>

Обратитесь к разделу [Распространение](#распространение), чтобы узнать больше о доступных параметрах конфигурации для каждого пакета
и о том, как распространять их среди пользователей.

:::note
Большинство платформ требуют подписи кода. См. раздел [Подпись](#подпись) для получения дополнительной информации.
:::

### Упаковка

По умолчанию команда `build` автоматически упаковывает ваше приложение для настроенных форматов.

Если вам нужна дополнительная настройка того, как создаются пакеты платформ, вы можете разделить этапы сборки и упаковки:

<CommandTabs
  npm="npm run tauri build -- --no-bundle
# bundle for distribution outside the macOS App Store
npm run tauri bundle -- --bundles app,dmg
# bundle for App Store distribution
npm run tauri bundle -- --bundles app --config src-tauri/tauri.appstore.conf.json"
  yarn="yarn tauri build --no-bundle

# bundle for App Store distribution

  pnpm="pnpm tauri build --no-bundle

# bundle for App Store distribution
pnpm tauri bundle --bundles app --config src-tauri/tauri.appstore.conf.json"
  deno="deno task tauri build --no-bundle

deno task tauri bundle --bundles app,dmg
# bundle for App Store distribution
deno task tauri bundle --bundles app --config src-tauri/tauri.appstore.conf.json"
  bun="bun tauri build --no-bundle
# bundle for distribution outside the macOS App Store
bun tauri bundle --bundles app,dmg
# bundle for App Store distribution
bun tauri bundle --bundles app --config src-tauri/tauri.appstore.conf.json"
  cargo="cargo tauri build --no-bundle

cargo tauri bundle --bundles app,dmg
# bundle for App Store distribution
cargo tauri bundle --bundles app --config src-tauri/tauri.appstore.conf.json"
/>

## Версионирование

Версия вашего приложения может быть задана в параметре конфигурации [`tauri.conf.json > version`],
что является рекомендуемым способом управления версией приложения. Если это значение конфигурации не задано,
Tauri вместо этого использует значение `package > version` из вашего файла `src-tauri/Cargo.toml`.

:::note
На некоторых платформах есть ограничения и особые случаи для строки версии.
См. отдельные страницы документации по распространению для получения дополнительной информации.
:::

## Подпись

Подпись кода повышает безопасность вашего приложения, применяя цифровую подпись к
исполняемым файлам и пакетам приложения, подтверждая вашу личность как поставщика приложения.

Подпись обязательна на большинстве платформ. См. документацию для каждой платформы для получения дополнительной информации.
