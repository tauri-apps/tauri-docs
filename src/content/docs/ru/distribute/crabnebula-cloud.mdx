[CrabNebula] — официальный партнёр Tauri, предоставляющий услуги и инструменты для приложений Tauri. [CrabNebula Cloud] — это платформа для распространения приложений, которая бесшовно интегрируется с обновлятором (updater) Tauri.

Облако предлагает сеть доставки контента (CDN), способную поставлять установщики и обновления вашего приложения по всему миру, оставаясь экономически эффективной и предоставляя метрики загрузок.

С помощью сервиса CrabNebula Cloud легко реализовать несколько каналов выпуска, кнопки загрузки для сайта вашего приложения и многое другое.

Настроить ваше приложение Tauri на использование облака просто: всё, что вам нужно сделать, — это войти на [сайт облака][Cloud website] с помощью учётной записи GitHub, создать организацию и приложение, а также установить его CLI, чтобы создать выпуск и загрузить бандлы Tauri. Кроме того, предоставляется [GitHub Action], упрощающий процесс использования CLI в рабочих процессах GitHub.

Дополнительную информацию см. в [документации CrabNebula Cloud][CrabNebula Cloud documentation].
